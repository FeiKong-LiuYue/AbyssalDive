## 二、核心类说明

| 类 | 职责 |
|----|------|
| **GameManager** | 总体协调，管理游戏状态（Menu/Preparation/Battle/Reward/GameOver） |
| **BattleSystem** | 战斗入口，驱动ATB循环，执行行动，处理胜负 |
| **ATBSystem** | 管理行动值积累，按速度累加，触发行动执行 |
| **ActionExecutor** | 执行具体行动效果，触发特性，施加状态 |
| **TriggerSystem** | 监听战斗事件（击伤/死亡/回合开始等），触发特性效果 |
| **DamageCalculator** | 计算伤害，处理护盾/护甲/易伤等 |
| **StateComponent** | 管理单位身上的状态（层数/衰减/消耗） |
| **StateResolver** | 回合结束时解析状态衰减，触发DOT伤害 |

## 三、触发框架（事件驱动观察者模式）

### 3.1 事件总线（EventBus）

```csharp
public class EventBus {
    public void Publish<T>(GameEventType type, T eventData);
    public void Subscribe(GameEventType type, IEventListener listener);
    public void Unsubscribe(GameEventType type, IEventListener listener);
}
```

### 3.2 事件类型

| 事件 | 说明 |
|------|------|
| TurnStart | 回合开始 |
| TurnEnd | 回合结束 |
| ActionExecuting | 行动执行前 |
| ActionExecuted | 行动执行后 |
| Attack | 发起攻击 |
| Hit | 造成击伤（实际伤害） |
| Damaged | 被攻击 |
| FollowUpTriggered | 追击触发 |
| CounterTriggered | 反击触发 |
| Death | 死亡 |
| Kill | 击杀 |
| ShieldBroken | 破盾（护盾归零） |
| ShieldDamaged | 碎盾（护盾减少但未归零） |
| StateAdded | 状态添加 |
| StateRemoved | 状态移除 |
| StateStackChanged | 状态层数变化 |

### 3.3 特性触发流程

```
EventBus.Publish(Hit, attacker=player, target=enemy, damage=10)
    ↓
遍历所有注册的监听者
    ↓
TraitA 关心 Hit 事件？Yes → 检查 condition（敌人血量<30%）→ 执行 effect（+6伤害）
TraitB 关心 Hit 事件？Yes → 检查 condition（无额外条件）→ 执行 effect（+护盾）
```

### 3.4 特性结构

```csharp
public class Trait {
    public string id;
    public string name;
    public int level;
    public GameEventType[] triggerEvents;  // 关心的事件类型
    public TriggerCondition condition;      // 触发条件
    public Effect effect;                    // 触发后的效果
}
```

## 四、状态系统

### 4.1 状态类型

| 类型 | 状态 | 规则 |
|------|------|------|
| 回合衰减型 | 易伤/虚弱/溃伤/守御/招架/坚壁/荆棘/碎盾/眩晕/治愈/威压/连击 | 每回合-1层 |
| 受击消耗型 | 铁壁 | 被物理攻击时-1层 |
| 永久叠层型 | 蓄势/战意/力量/狂怒 | 无衰减，战斗结束清空 |
| 主动消耗型 | 蓄力/疫病/奇袭/警戒 | 触发后减少1层 |

### 4.2 状态效果触发

| 状态类型 | 触发方式 |
|----------|----------|
| 回合衰减型 | TurnStart 事件中自动处理 |
| 受击消耗型 | Damaged 事件中处理（铁壁） |
| 永久叠层型 | 战斗结束自动清空 |
| 主动消耗型 | Hit/Counter 等事件触发后减少层数 |

## 六、战斗流程

### 6.1 ATB行动值循环

```
1. 回合开始
   → 所有单位按速度积累行动值
   → 状态衰减处理（DOT/回合衰减）
   → 特性触发（TurnStart相关）

2. 执行行动
   → 行动值达标单位按行动值高低排序
   → 行动值最高者执行行动
   → 扣除行动值消耗，保留余量

3. 行动效果
   → 执行效果
   → 触发特性检查
   → 可能触发追击/反击

4. 回合结束
   → 特性触发（TurnEnd相关）
   → 状态衰减检查
```

### 6.2 伤害计算

```
最终伤害 = (基础伤害 × 属性加成 + 固定加成 + 状态附加) × 伤害倍率 - 护盾抵扣 - 护甲减免
```

## 七、设计原则

1. **数据与逻辑分离** - ScriptableObject 存储数据，C# 类处理逻辑
2. **事件驱动** - 通过 EventBus 解耦特性与战斗系统
3. **组件化** - 单位由独立组件组成（Health/Shield/State等）
4. **可扩展** - 添加新特性不需要修改战斗核心代码
