## 三、游戏机制

### 六大核心机制

| 机制 | 说明 |
|------|------|
| 击伤 | 核心伤害触发，造成实际生命值扣除 |
| 连击 | 多次攻击相关，累积层数触发追加攻击 |
| 蓄力 | 临时物理伤害加成，一次性消耗 |
| 护盾 | 独立于生命值的防护系统 |
| 溃伤 | 持续伤害（溃伤统一） |
| 基础类 | 简单浅机制内容 |

### 属性系统

| 属性 | 效果 |
|------|------|
| 攻击 | 影响物理伤害 |
| 血量 | 生命值上限 |
| 护甲 | 与护盾等机制联动 |
| 速度 | 决定每回合行动值积累量 |

### ATB行动值系统

- 速度：固定属性，决定每回合行动值积累量
- 行动值：战斗内实时数值，每回合按速度累加
- 行动门槛：每个行动有固定消耗门槛，攒够≥门槛即可执行

## 五、界面流程

```
主菜单
├── 继续下潜 → 战备界面 → 战斗界面 → 战斗奖励 → 战备界面...
└── 开始下潜 → 战备界面 → 战斗界面 → 战斗奖励 → 整局结算 → 主菜单
```

## 六、设计风格

- 风格：暗调废墟暗黑风、偏厚重、做旧、蚀刻、裂纹
- 底色：焦黑底色（#121014）+ 深渊暗纹
- 配色：暗金（关键）、幽蓝（常规）、暗红（危险）
- 动效：按下荧光亮起+符文闪烁
