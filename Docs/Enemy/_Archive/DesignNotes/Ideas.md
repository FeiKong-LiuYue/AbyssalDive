## 状态联动型

| 概念 | 效果 |
|------|------|
| 中毒引爆 | 中毒层数越高，受伤越重 |
| 护盾转化 | 护盾破碎时转化为攻击力 |
| 易伤叠加 | 易伤层数影响下次伤害倍率 |

---

## 行动协同型

| 概念 | 效果 |
|------|------|
| 连续打击 | 每次攻击叠加伤害 |
| 蓄力爆发 | 蓄力层数影响伤害 |
| 协同攻击 | 同伴在场时伤害提升 |

---

## 特性互动型

| 概念 | 效果 |
|------|------|
| 狂怒连锁 | 击杀敌人后狂怒层数转移给同伴 |
| 护盾共鸣 | 护盾层数影响伤害反弹 |
| 虚弱传染 | 对虚弱敌人造成更多伤害 |

## 生存消耗型

| 概念 | 效果 |
|------|------|
| 血量护甲 | 血量越低护甲越高 |
| 牺牲攻击 | 扣血换伤害 |
| 生命汲取 | 造成伤害回复血量 |

## 敌人原型创意

### 控制型
- 减速、虚弱、眩晕等debuff施加
- 限制玩家行动选择

### 爆发型
- 低血量时伤害大幅提升
- 特定条件下触发高额伤害

### 持续型
- 每回合稳定输出
- 状态逐渐叠加

### 协作型
- 多敌人配合产生增益
- 击杀一个触发另一个的机制
