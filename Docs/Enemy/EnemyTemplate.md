## 一、文档结构

所有敌人文档必须包含以下部分：

```
# EN-X-XXX 敌人名称

## 概述

| 字段 | 内容 |
|------|------|
| ID | EN-X-XXX |
| 名称 | 敌人名称 |
| 所属池 | 池X（阶段X，普通层X-X） |
| 定位 | 定位描述 |
| 多敌遭遇 | 支持/强制多敌/单独 |
| 世界观 | 世界观简述（可选） |

---

## 属性

| 属性 | 数值 |
|------|------|
| 攻击力 | X |
| 血量 | X |
| 护甲 | X |
| 速度 | X.X |

---

## 行动

| 行动 | 效果 | 消耗 |
|------|------|------|
| 行动1 | 效果描述 | X |
| 行动2 | 效果描述 | X |
| 行动3 | 效果描述 | X |

---

## 特性

| 特性 | 效果 | 触发条件 |
|------|------|----------|
| 特性1 | 效果描述 | 触发条件 |

---

## 机制分析（可选）

### 核心机制

- 机制1
- 机制2

### 玩家应对

- 应对策略
```

---

## 二、格式规范

| 项目 | 规范 |
|------|------|
| 属性 | 使用具体数值，不使用"偏高/中等/偏低"等描述 |
| 行动消耗 | 填写具体数值，不使用"待定" |
| 特性描述 | 清晰说明效果和触发条件 |
| 多敌遭遇 | 明确标注支持/强制多敌/单独 |
