## 核心设计原则

### Abyssfall敌人设计核心

> **玩法核心**：行动和特性之间的联动 + 行动前后衔接的叠加

敌人由**行动**和**特性**组成：
- **行动**：敌人主动执行的技能，效果与玩家行动类似
- **特性**：敌人被动触发的机制，条件满足时自动生效

设计应专注于**六大核心机制**：

| 机制 | 说明 |
|------|------|
| 击伤 | 触发条件：击伤时追加伤害/状态/行动 |
| 连击 | 多次攻击：连击层数加成、连击追加攻击 |
| 蓄力 | 临时伤害加成：蓄力伤害、消耗蓄力效果 |
| 护盾 | 防护系统：护盾攻防、护盾转化 |
| 溃伤 | 持续伤害：溃伤施加、溃伤DOT |
| 基础类 | 简单效果：回血、buff施加、状态施加 |

### 扩展机制（可选）

| 机制 | 说明 |
|------|------|
| 状态复制 | 复制玩家身上的增益/减益状态 |
| 属性偷取 | 偷取玩家的属性（攻击/防御/速度等） |
| 协同增益 | 同伴存在时获得增强 |
| 时空错位 | 额外行动、预判、回合干扰 |
| 献祭 | 牺牲自身属性/血量换取强大效果 |
| 诅咒 | 对玩家施加长期debuff（不影响行动流转） |

## 待整理概念

### 概念A：镜像敌人

- 敌人能复制玩家身上的某个正面buff给自己
- 玩家使用什么技能，敌人有几率模仿
- 但复制有延迟，不是即时

### 概念B：时空错位

- 敌人部分行动会产生"时序混乱"
- 比如：本回合结束时，敌人额外行动一次
- 或者：本回合开始时，敌人已经"预判"了玩家上回合使用的技能

### 概念C：献祭型敌人

- 敌人通过牺牲自己的血量/护盾/状态来获得强大效果
- 或者：牺牲自己的行动次数来强化单次行动效果

## 玩家行动设计想法

### 概念：代价型行动（永久增益全局属性）

> 设计一些永久增加全局属性的行动，但对战斗没有好处甚至有负面影响

**核心设计思路**：
- 玩家使用行动获得某种长期增益（如金币、经验、任务进度）
- 代价是战斗属性下降（如攻击力降低、获得debuff）
- 或者触发某种负面事件

**示例设计**：

| 行动 | 长期增益 | 战斗负面影响 |
|------|---------|-------------|
| 献祭生命 | +10%金币获取 | 血量上限-5 |
| 灵魂绑定 | 解锁隐藏任务线 | 受到的灵魂伤害+20% |
| 贪婪印记 | +5%掉落稀有物品 | 攻击力-10% |
| 契约代价 | 获得强力装备 | 每场战斗开始获得1层易伤 |
| 诅咒转化 | 属性永久+2 | 速度-0.5 |

**设计意图**：
- 增加玩家决策的深度和后果
- "要不要用战斗外的优势换取长期收益"
- 制造有趣的两难抉择
- 不影响战斗行动流转，仅影响属性/状态

## 设计约束记录

1. 不干涉玩家行动自由
2. 不强制修改玩家行动值
3. 不封禁、冻结、封印玩家行动
4. 敌人行动链应形成闭环
