## 概述

| 字段 | 内容 |
|------|------|
| ID | EN-D-002 |
| 名称 | 墟眠古骸 |
| 所属池 | 池D（阶段4，普通层16-19） |

| 世界观 | 沉眠于遗墟深层的古老骸体，长守墟眠状态静静吸纳渊能。受创惊醒后迸发醒世一击，旋即再度沉入墟眠，往复循环，缓缓变强 |

---

## 属性（阶段4锚点）

| 属性 | 数值 |
|------|------|
| 攻击 | 低（睡眠中）/ 高（惊醒后） |
| 血量 | 高 |
| 护甲 | 高 |
| 速度 | 低（睡眠中）/ 高（惊醒后） |

---

## 行动槽位

| 槽位 | 行动 | 消耗 | 效果 |
|------|------|------|------|
| 槽位1 | 内嵌·惊醒攻击 | 待定 | 高额伤害，惊醒时触发 |
| 槽位2 | 内嵌·墟眠重归 | 待定 | 重新进入睡眠状态，恢复少量血量，叠加护盾 |

---

## 特性/被动

| 特性 | 效果 |
|------|------|
| E-PASS-SLEEP-CYCLE | 战斗开始时进入睡眠状态（不参与战斗，回合开始恢复血量）；受到攻击时惊醒，触发惊醒攻击；执行完惊醒攻击后重新进入睡眠状态 |
| E-PASS-SLEEP-STACK | 每次进入睡眠，攻击力+、血量上限+ |

---

## 玩家应对

在睡眠期间集火输出，争取惊醒后下一回合击杀
