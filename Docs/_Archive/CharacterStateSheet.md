## 一、战斗状态（CombatState）

### 1.1 通用规则

| 规则 | 说明 |
|------|------|
| 底层统一 | 所有状态均为「层数载体」，效果与层数挂钩 |
| 叠加规则 | 同类型累加层数，不覆盖、不重置 |
| 独立共存 | 不同类型状态可共存，互不抵消 |
| 护盾不免疫 | 护盾只挡伤害，不阻止状态施加 |

### 1.2 状态消耗类型

| 类型 | 状态 | 消耗规则 |
|------|------|----------|
| 回合衰减型 | 易伤 / 虚弱 / 伤口 / 毒素 | 每回合自动 −1 层，不受击消耗 |
| 受击消耗型 | 铁壁 | 不回合衰减，被物理攻击时消耗 1 层 |
| 永久叠层型 | 战意高涨 | 只叠层、不衰减、不消耗，战斗结束清空 |

### 1.3 状态列表（7 个）

---

#### 1. 战意高涨（正向增益）

| 规则 | 说明 |
|------|------|
| 获取 | 自身回合开始时自动 +1 层 |
| 层数上限 | 无上限 |
| 衰减 | 无自然衰减 |
| 消耗 | 不被攻击消耗 |
| 效果 | 层数越高，全局伤害加成越高 |
| 清除 | 战斗结束清空层数 |

---

#### 2. 易伤（负向）

| 规则 | 说明 |
|------|------|
| 获取 | 行动 / 敌人机制施加，累加层数 |
| 层数上限 | 无上限 |
| 衰减 | 每回合自动 −1 层 |
| 消耗 | 不受击消耗 |
| 效果 | 层数越高，受到所有伤害越高 |

---

#### 3. 虚弱（负向）

| 规则 | 说明 |
|------|------|
| 获取 | 行动 / 敌人机制施加，累加层数 |
| 层数上限 | 无上限 |
| 衰减 | 每回合自动 −1 层 |
| 消耗 | 不受击消耗 |
| 效果 | 层数越高，自身造成伤害越低 |

---

#### 4. 伤口（DOT 负向）

| 规则 | 说明 |
|------|------|
| 获取 | 物理攻击、反伤机制施加，累加层数 |
| 层数上限 | 无上限 |
| 衰减 | 每回合自动 −1 层 |
| 消耗 | 不受击消耗 |
| 效果 | 层数越高，回合结束流血 DOT 伤害越高 |
| 结算 | 每回合结束独立结算 |

---

#### 5. 毒素（DOT 负向）

| 规则 | 说明 |
|------|------|
| 获取 | 腐蚀、毒域、敌人技能施加，累加层数 |
| 层数上限 | 无上限 |
| 衰减 | 每回合自动 −1 层 |
| 消耗 | 不受击消耗 |
| 效果 | 层数越高，回合结束腐蚀 DOT 伤害越高，轻微无视护盾 |
| 结算 | 每回合结束与伤口同时独立结算 |

---

#### 6. 铁壁（防御型）

| 规则 | 说明 |
|------|------|
| 获取 | 通过行动 / 特性获得，固定层数 |
| 层数上限 | 无人为硬上限 |
| 衰减 | 不随回合自然衰减 |
| 消耗规则 | 每次受到物理攻击时，先减少 1 层铁壁，再结算伤害 |
| 触发 | 受到物理攻击瞬间 |
| 效果 | 铁壁层数越多，可抵挡的物理攻击次数越多；每层抵消一次物理伤害全额 |
| 逻辑 | 可叠层数 → 逐次受击逐层消耗 → 层数耗尽后消失 |

#### 7. 护盾（战斗属性状态）

|| 规则 | 说明 |
||------|------|
|| 获取 | 行动、特性、敌人机制等途径获得 |
|| 叠加 | 同源护盾值直接叠加（临时护盾与基础护盾分开累计） |
|| 衰减 | 每回合开始时减半（向下取整），临时护盾在持续回合结束后一次性清除 |
|| 消耗 | 护盾优先于生命承受物理伤害；耗尽后剩余伤害扣减生命 |
|| 结算顺序 | 先扣护盾 → 再扣铁壁（如有） → 最后扣生命 |
|| 清除 | 战斗结束清除所有护盾 |
|| 临时护盾 | 有持续回合限制的护盾，叠加在基础护盾之上，优先消耗 |

---

### 1.4 回合流程时序

```
1. 回合开始
   - 战意高涨自动叠层
   - 护盾减半（向下取整）
   - 所有单位按速度积累行动值
2. 行动值达标单位按高低依次行动
3. 行动结算
   - 造成伤害
   - 施加各类战斗状态层数
4. 受到物理攻击时
   - 铁壁层数 −1
   - 触发铁壁免伤效果
   - 结算护盾、减伤、生命扣除
5. 回合结束
   - 结算伤口、毒素 DOT 伤害
   - 易伤、虚弱、伤口、毒素每回合自动衰减 1 层
```

## 二、角色特性（CharacterTrait）

### 2.1 通用规则

| 规则 | 说明 |
|------|------|
| 等级 | **1～2 级**数值递增，**第 3 级⚡质变（满级）**；与 `ActionSheet.md` 行动同为**三级封顶**，不设第 4 级 |
| 质变 | 第 3 级在数值封顶或机制条目的基础上附加联动、解锁新被动 |
| 触发 | 被动自动触发，完全适配自动战斗 |
| 奖励 | 抽到已有特性则升级，升至 **3 级满级**后随机替换新特性 |
| 稀有度 | 普通 / 稀有 / 精英 三层 |
