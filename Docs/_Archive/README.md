# 游戏玩法重构

> 状态：进行中

---

## 核心循环

```
下潜 → 触发战斗 → 战备（切换上阵行动）→ 自动战斗 → 胜利获得奖励 → 继续下潜 / 失败重置
```

---

## 系统精简

| 系统 | 保留？ | 说明 |
|------|--------|------|
| 行动 | ✅ | 战斗中使用的行动 |
| 角色特性 | ✅ | 被动触发的效果 |
| 角色状态 | ✅ | 战斗中的数值/层数 |
| 遗物 | ❌ | 删除 |
| 词条 | ❌ | 删除 |
| 外循环（搜打撤） | ❌ | 删除 |
| 多区域 | ❌ | 删除 |
| 局外成长 | ❌ | 删除 |

---

## 战斗流程

```
1. 下潜（触发战斗）
   ↓
2. 战备阶段（切换上阵行动）
   ↓
3. 自动战斗（玩家不操作）
   ↓
4. 战斗结算
   ↓
5. 胜利 → 获得奖励 → 继续下潜
   失败 → 重置
```

---

## 战备阶段

| 设计 | 说明 |
|------|------|
| 可配置项 | 切换上阵行动 |
| 行动栏（槽位） | **初始 3** 格，**最高 5** 格 |
| 开战条件 | **须填满**当前已解锁的全部栏位（每格 1 个行动，同一行动可重复）；**未满不可开战** |
| 执行顺序 | 按填入顺序执行（同一行动可重复使用） |

---

## 自动战斗

| 设计 | 说明 |
|------|------|
| 玩家操作 | 无 |
| 执行方式 | 按行动槽顺序执行 |
| 执行逻辑 | 轮到某行动时自动执行该行动效果 |
| 影响因素 | 角色特性、角色状态 |
| 循环 | 行动槽执行完后，从第一个开始循环 |
