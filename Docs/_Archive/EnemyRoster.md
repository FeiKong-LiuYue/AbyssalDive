# 敌人条目表（精简版）

> 与 `EnemyDesign.md` 配套；数值为占位，待接阶段曲线。  
> **组稿方法**：先按 `EnemyDesign.md` §1.2.1 从行动库 / 被动库选零件，再在本表为**每一条敌人**写清「槽位组合 + 数值」；库内单行描述**不会自动生效**，必须挂到条目上。
> **多敌决策**：已确认开放多敌遭遇（2～4 个敌方单位同场）。护伴型（§1.4）/ 分裂型（§1.5）条目**强制多敌**，不可进入单敌池。

---

## 条目模板（复制后改 ID）

| 字段 | 填写说明 |
|------|----------|
| **条目 ID** | 如 `EN-A-00X` |
| **显示名** | |
| **所属池 / 权重** | 池 A～D 或 Boss 池；随机权重 |
| **原型标签** | 可选：`BRUTE` / `CONTROL` / … |
| **被动** | 无；或列表：`E-PASS-xxx（参数…）` |
| **特色引用** | 无；或 `§1.4 护伴` / `§1.4.1 双倍代承` / `§1.5.1 死亡分裂` / `§1.5.2 限时分裂` / `§1.6 自爆` / `§1.7 限时进化` + 子参数摘要 |
| **槽位 1** | `行动模板ID`；消耗：**N**；条目参数：**…** |
| **槽位 2** | 同上（无则删行） |
| **槽位 3** | 同上（无则删行） |
| **内嵌普攻** | 若某槽为「敌人普通攻击」而非库 ID，写明倍率与伤害类型 |
| **属性（阶段锚点）** | 攻/血/护/速：数值或「锚点 + 修正」 |
| **图标 / 立绘** | 资源键 |
| **多敌遭遇** | 本条目是否支持多敌同场（2～4 个敌方单位）；护伴/分裂型条目默认**强制多敌**，不可进入单敌池 |

## 多敌协同羁绊（组合效果）

> 以下组合在多敌同场时触发专属增益；在 `EnemyRoster` 中同时出现以下组合时激活：

| 组合 | 触发条件 | 效果 |
|------|----------|------|
| **哨卫 + 祭者** | 墟骨哨卫与纹盾祭者同场 | 结界展开时触发警觉，结界强化（全队攻速 + 护盾增幅） |
| **咒骸 + 古尸** | 蚀影咒骸与静滞古尸同场 | 冻结玩家节奏 + 封禁行动，双重控制彻底掌控战斗 |
| **畸兽 + 棺卫** | 噬层畸兽与沉渊棺卫同场 | 回合越久 → 畸兽越强 + 棺卫觉醒越晚越爆发，形成拖回合即败 |
| **引路人 + 哨卫** | 残魂引路人与墟骨哨卫同场 | 魂链建立后哨卫警觉速度 ×2，组合极易触发全员强化 |
