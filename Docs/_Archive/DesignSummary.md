- 攻击

- 护甲（不直接参与伤害计算，仅与护盾等机制联动）
- 速度（基本固定不变）

## 战斗流程（每回合）

```
1. 回合开始
   - 护盾减半（向下取整）
   - 所有单位（玩家+敌人）积累行动值（速度决定每回合积累量）
2. 行动值攒满的单位按行动值高低顺序执行行动
3. 回合结束

【战斗开始】
- 每次战斗，双方以满血开始
```

### 多敌机制

- 单场战斗可容纳 **2～4 个敌方单位**
- 敌人共享行动值积累系统，按行动值高低排序轮动
- 玩家攻击可选择目标或随机
- 护伴型 / 分裂型敌人**强制多敌**（必须同场有同伴才可配置），不可进入单敌池

### 行动值系统

- 速度决定每回合积累的行动值量
- 不同行动有不同行动值消耗
- 玩家上阵的行动按队列顺序执行
- 队列内循环，每个循环从头执行一次
- 仅战备阶段可调整行动队列

### 护盾机制

- 吸收物理伤害（护甲参与护盾相关计算）
- 仅回合开始时减半（向下取整）
- 耗尽后剩余伤害扣除生命值

### 伤害计算

- 攻击力影响伤害
- 不同行动有不同伤害计算方式
- 护甲不直接参与伤害计算

## 战备阶段


| 设计   | 说明                 |
| ---- | ------------------ |
| 可配置项 | 切换上阵行动             |
| 行动栏（槽位） | **初始 3** 格，**最高 5** 格 |
| 开战条件 | **须填满**当前已解锁的全部栏位（每格 1 个行动，同一行动可重复）；**未满不可开战** |
| 执行顺序 | 按填入顺序执行（同一行动可重复使用） |

| 设计   | 说明               |

| 玩家操作 | 无                |

## 阶段奖励

### 奖励类型

- 行动解锁和升级奖励
- 角色特性（含属性）解锁和升级奖励
- **行动栏栏位解锁奖励**（第 4 格 / 第 5 格）

### 奖励方式

- 每次战斗胜利都有奖励（三选一）
- BOSS 战奖励更好（稀有度权重提升）
- 从奖励池中抽取 3 个选项，选择 1 个
- 行动与特性随机混合出项（比例随机）

### 奖励池结构

- 全量池，按阶段分层稀有度权重：阶段越高，高稀有度奖励出现概率越大
- 抽取范围：从未解锁或未升级满的行动/特性中抽取
- 升级已满的条目不会出现在奖励池中

### 行动栏扩容规则

- 第 4 格和第 5 格解锁**仅通过奖励**实现
- 解锁后新格为**空槽**，可放入任意已解锁行动
- 未填满全部已解锁栏位时**不可进入战斗**

### 阶段强化（第 5/10/15/20 层）

- 形式：**三选一**（与普通战斗奖励相同）
- 区别：奖池稀有度权重进一步向高稀有度倾斜（比同阶段普通战斗更高）
- 额外解锁：阶段强化后，可能出现该阶段独有的强力行动/特性（特定稀有度以上才可抽取）

## 敌人机制

- 敌人使用相同的行动值系统
- 敌人没有战备阶段
- 敌人也有特性和状态
- **展开设计**：`[EnemyDesign.md](EnemyDesign.md)`（层段敌人池、随机遭遇、条目唯一性、Boss）
- 各阶段普通层有**多个**具体敌人配置；遭遇时**随机抽取**；每个敌人有独立行动顺序、机制、属性与图标
