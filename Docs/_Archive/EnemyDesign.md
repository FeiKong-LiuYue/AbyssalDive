## 1. 通用规则


| 项目    | 设计                               |
| ----- | -------------------------------- |
| 属性    | 与玩家同维度：攻击、血量、护甲、速度（速度基本固定）       |
| 战斗开始  | 双方满血（见总设）                        |
| 行动值   | 与玩家同一套积累与执行规则                    |
| 行动栏   | 2～3 个行动；至少 1 个攻击向；栏内循环执行         |
| 战备    | 无；遭遇即按配置行动栏开战                    |
| 特性/状态 | 可有；与玩家侧同一套语义（物理、护盾、伤口、易伤、虚弱、**迟缓**（战斗内速度修正）、眩晕等） |
| 伤害环境  | 仅物理（与总设一致）                       |


### 1.1 AI 原则（初稿）

- 敌人**不**在战斗中改栏；行动栏由**该敌人条目**的配置固定。
- 轮到敌人且行动值满足下一招消耗时，执行「当前指针」指向的行动，然后指针进位（循环）。
- **同 tick 多单位可动**：仍按「行动值高低」决定先后顺序；敌人与玩家混排。
- 若需体现「狂乱/迟疑」等性格，通过**行动消耗不同**或**附加被动特性**表达，不单独做复杂行为树（首版）。
- 若条目挂载 **`E-PASS-FORCE-CHARGE-UNTIL-FIRST-HIT`**（**被攻击前**仅蓄力），在**破蓄**前覆盖本节「按指针循环栏位」的默认行为，**破蓄**后恢复；见 §1.3.1。

### 1.2 敌人条目（唯一性）

每个具体敌人（非抽象「原型」）在数据上是一条完整配置，**彼此独立**，包含但不限于：


| 维度      | 说明                                                 |
| ------- | -------------------------------------------------- |
| 身份      | 唯一 ID、显示名                                          |
| 图标 / 视觉 | 战斗 HUD、图鉴等用图标；可扩展立绘                                |
| 属性      | 攻击、血量、护甲、速度（可挂阶段倍率表）                               |
| 行动栏     | 2～3 个行动；**栏位顺序即循环顺序**，体现该敌人独有节奏                    |
| 机制      | 被动特性、开局状态、特殊规则（如某招后强制切指针）——按条目配置，不与其它敌人共用同一套「模板实例」 |
| 行动值消耗   | 每条目可为各行动单独填消耗（同一「技能名」在不同敌人身上可不同）                   |

### 1.2.1 从「库」组稿为「一个敌人」（行动槽 + 定制）

> §1.3 **行动库**、§1.3.1 **被动库**、§1.4 / §1.5 **大块特色**里的描述都是**可复用零件**。真正上场的是 **`EnemyRoster.md` 里的一条敌人条目**：在同一条目内，把选中的零件**组合进固定行动栏**，并写上**本条专属数值**，才算「定制完成」。

**组稿顺序（建议）**

1. **定定位**：池子（A/B/C/D 或 Boss）、难度档、原型标签（可选）。
2. **组行动栏（2～3 格）**：从 §1.3 选 **行动模板 ID**（同一 ID 可在不同敌人身上复用）；按 **槽位 1 → 2 → 3** 排列，顺序即 **循环出招顺序**。
3. **写条目级参数**：每个槽位至少填：**`行动模板ID` + 本敌人该招的 `行动值消耗` + 模板内占位参数（X/Y/层数等）在本条目的具体数字**（可覆盖模板默认）。
4. **挂被动（0～N）**：从 §1.3.1 选 **被动模板 ID**，在条目中列出，并填 **X/Y/上限** 等；无则写「无」。
5. **挂大块机制（可选）**：若本敌人需要 **护伴 / 分裂** 等，在条目中 **显式引用 §1.4 / §1.5**，并写子参数（否则不写，避免隐式全局机制）。
6. **填四维与美术**：攻击、血量、护甲、速度（或引用阶段锚点 + 修正）；图标/立绘键。
7. **入池与权重**：写入对应池的随机表。

**定制与复用的边界**

| 层级 | 内容 |
|------|------|
| **模板（库）** | 统一文案与默认语义；便于策划对齐称呼。 |
| **条目（Roster）** | **唯一组合**：哪几招进槽、顺序、每招消耗与数值、带哪些被动、是否带分裂/护伴子规则——这些差异定义「这是哪一个敌人」。 |

**校验清单（条目定稿前）**

- [ ] 至少 **1** 格为攻击向（或能造成伤害的行动）。
- [ ] 每格 **行动值消耗** 已填，且与 intended 节奏（快/慢）一致。
- [ ] 若行动含「下一次攻击×2/×3」「随机封锁玩家行动」等，已写清 **与单敌/多敌场次** 的降级或前提。
- [ ] 若含 **`E-PASS-ACTION-GATE-WHILE-ALLIES-LIVE`**（同伴未全灭前锁行动），已列出**被锁槽位**及**单敌遭遇**下的行为（无同伴时是否整条目禁用）。
- [ ] 若含 **`E-PASS-FORCE-CHARGE-UNTIL-FIRST-HIT`**（被攻击前仅蓄力），已写明**蓄力行动模板 ID**、**蓄力槽位**及**破蓄**判定（与护盾/前几击免伤等交互若存在）。
- [ ] 若含 **`E-PASS-BACKLOG-DEATH-BURST`**（积压殉爆），已写明**+1 积压的触发**、**B/k（或伤害表）**、**死亡爆发与分裂/复活**的结算顺序。
- [ ] 被动与行动无未解释的 **参数占位**（X/Y）遗漏。

具体条目书写格式见 **`EnemyRoster.md`** 中的「条目模板」与示例。

### 1.3 敌人行动库（草案）

> 下列为**敌人专用**行动模板，可挂入任意敌人条目的行动栏；与玩家 `ActionSheet.md` **不强制同名同效果**，若复用语义需在条目里写明。


| 行动 ID                           | 暂定显示名           | 效果                                                                                                                    |
| ------------------------------- | --------------- | --------------------------------------------------------------------------------------------------------------------- |
| E-ACT-STACK-STRENGTH-AURA | 战意积淀 | 获得/叠加 1 层**战意积淀**状态；**每个回合开始时**自身获得 **+Y** 力量（**Y** 由 `EnemyRoster` 填值）。与玩家侧「蓄力」为**独立系统**，不共用 ID。 |
| E-ACT-CHARGE-TICK | 战意蓄积（敌人专用） | **无伤害**；自身获得 **战意层**（叠层规则见本行动模板注释；与玩家「蓄力」**完全独立**）。常用于被动 **`E-PASS-FORCE-CHARGE-UNTIL-FIRST-HIT`**（见 §1.3.1）：**被攻击前**反复执行本格。层数上限由 `EnemyRoster` 填实。 |
| E-ACT-APPLY-STUN | 震击 | 对目标施加 **1 层眩晕**（复用 `RS-DEBUFF-STUN`；层数叠加与行动值消耗规则见玩家侧眩晕定义）。 |
| E-ACT-APPLY-SLOW-STACK | 缚足 | 对目标（默认**玩家**）施加 **1 层「迟缓」**：有效速度 -1/层（多层线性叠加；速度下限 ≥ 1）；状态 ID 与玩家侧**迟缓**状态**共用**。持续 N 回合、是否可驱散：条目写明。 |
| E-ACT-RANDOM-ACTION-LOCK | 乱序封禁 | 使目标（玩家）**随机一个已上阵行动**在本场战斗中**暂时无法执行**；持续口径在 `EnemyRoster` 写明（持续 X 回合 / 直到某条件解除等）。 |
| E-ACT-SELF-NEXT-TRIPLE-STRIKE | 三连蓄势 | 使自身**下一次攻击**连续发起 **三次**（同一目标；三次是否各自独立判定命中/触发：在 `EnemyRoster` 写明）。 |
| E-ACT-STRIKE-GAIN-SHIELD | 刃盾连击 | 对目标（默认**玩家**）造成**物理伤害**（倍率或平直数值 **X**，`EnemyRoster` 填）；同一结算流程内自身获得 **Y 点护盾**（复用 `CharacterStateSheet.md` 护盾状态 ID）。伤害与护盾的先后顺序在 `EnemyRoster` 写明。 |
| E-ACT-STRIKE-HEAL-ON-WOUND | 噬命斩 | 对目标（默认**玩家**）发起**物理攻击**（倍率或平直 **X**，`EnemyRoster` 填）。若攻击结算中**击伤**目标，自身**回复 Y 点生命**（**Y** 为条目参数；击伤判定仅计 HP 实际减少，护盾吸收未扣血不计入）。多段伤害每段分别判定或整次至多回一次：由 `EnemyRoster` 写明。 |
| E-ACT-BULWARK-GAMBIT | 危盾赌局 | **无伤害**（或条目约定极低伤，在 `EnemyRoster` 写明）。自身获得**高额护盾**（复用护盾状态 ID，`EnemyRoster` 填 Y 值），并挂**「赌盾」标记**（占位名，正式名与图标在 `EnemyRoster` 写明）。**判定窗口**：本格结算结束起，至本敌人**下一次**对玩家造成物理伤害的那格**攻击完成结算**前——若护盾**仍有剩余**（未击破），该次攻击**最终伤害 ×2**；若护盾已被清空（击破），对自身施加**眩晕**（复用 `RS-DEBUFF-STUN`）。 |
| E-ACT-ALLY-RANDOM-DOUBLE-STRIKE | 战群号令 | 使**随机一名同伴**的**下一次攻击**发起 **两次**（需场上存在其它敌方单位；若仅单体遭遇则本格无效或对自身生效，在 `EnemyRoster` 写明）。 |
| E-ACT-ALLY-HEAL | 同伴疗愈 | **回复一名同伴 X 点生命值**（**X** 为条目参数）。治疗目标判定规则在 `EnemyRoster` 写明（固定配对 / 血量最低同伴 / 随机等）。 |
| E-ACT-STANCE-STRENGTH-ON-HIT | 聚势架式 | 执行本格时获得**架式状态**（占位名，正式名在 `EnemyRoster` 写明）：在**本敌人下一次从行动栏执行任意行动之前**，每次**被攻击**时自身**力量 +Y**（**Y** 为条目参数；力量语义与玩家侧一致）。下一次行动执行完毕后该架式解除。 |
| E-ACT-STANCE-HALF-DAMAGE-TAKEN | 铁壁架式 | 执行本格时获得**架式状态**（占位名，正式名在 `EnemyRoster` 写明）：在**本敌人下一次从行动栏执行任意行动之前**，自身**受到的伤害按 50% 结算**（先于护盾/护甲计算）。下一次行动执行完毕后该架式解除。 |


**待细化**

> 以下为仍需在 `EnemyRoster` 或工程实现时填明的条目级细节，不在本模板层讨论：
>
- 「负面」包含哪些状态（虚弱、易伤是否算在敌身上的「负面」、伤口是否可驱散等）。
- 行动值消耗、等级/稀有度（若敌人行动也分级）。
- 层数上限（由 `EnemyRoster` 填实）。
- **E-ACT-APPLY-SLOW-STACK**：与超速缩放、行动值阈值叠加时，迟缓参与在缩放前还是后；涤秽类清除负面是否移除迟缓。
- **E-ACT-RANDOM-ACTION-LOCK**：「无法执行」是否跳过栏位、是否仍消耗行动值/回合、是否可对同一行动重复叠加、随机选取是否加权。
- 「下一次攻击」指行动栏下一格还是下一次造成伤害的行动；三次/两次是否同目标。
- **E-ACT-STRIKE-GAIN-SHIELD**：攻击被闪避/未命中时是否仍获得护盾；多段伤害每段叠盾还是整次只叠一次。
- **E-ACT-STRIKE-HEAL-ON-WOUND**：攻击未命中、被闪避、伤害为0是否触发回血。
- **E-ACT-ALLY-HEAL**：满血溢出是否转护盾；与伤口、治疗抑制的交互；多敌同场时 UI 提示。

### 1.3.1 敌人被动/特性模板（草案）

> 与 **§1.3 行动库**区分：下列为可挂在**敌人条目**上的被动简述；具体层数、上限与触发口径在条目或状态表中填实。


| 被动 ID              | 暂定显示名          | 效果                                                                                                                                                 |
| ------------------ | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| E-PAS-WOUND-STR    | 待定             | **击伤**目标时，增加自身**力量**：每次满足条件的击伤获得 **Y** 层力量（力量语义与玩家侧一致，见 `ActionSheet.md` / `CharacterStateSheet.md`）；**每次击伤叠几层**、**力量层数上限**、是否与其它来源力量合并结算：**待定**   |
| E-PASS-OFFENSE-TAX | 攻势反噬 / 噬力场（暂定） | **对方**每次发起一次攻击，力量 **-1**。从**敌人视角**解读文案：「**对方**」= **玩家**；即 **玩家每发起一次攻击**，**玩家**的**力量** **-1**（或「**力量**」层数 **-1**，与 `CharacterStateSheet` 口径**待定**）。 |
| E-PASS-TURN-DRAIN-TARGET-HP | 回合放血 / 枯潮（暂定） | 在**每个回合**的约定时点（**回合开始** / **回合结束** / **敌我回合边界**：**待定**；须与全局「回合」定义及 `E-ACT-STACK-STRENGTH-AURA` 等**对齐**），使**目标**（默认**玩家**）**失去 X 点生命**。实现口径二选一（`EnemyRoster` **写死**）：**(a)** 视为一次 **X** 的**物理伤害**（参与**护甲、护盾、易伤**等常规管道）；**(b)** **真实生命流失**（**无视护甲**、是否仍先扣护盾：**待定**）。**X** 为条目参数；开战**首回合**是否触发、本敌人**尚未行动过**是否仍触发：**待定**。是否归入 **DoT**、与**伤口**、**治疗抑制**的交互：**待定**。 |
| E-PASS-PHYSICAL-DAMAGE-CAP   | 硬壳限伤 / 伤害阈值（暂定）    | 每次受到的**物理伤害**不超过 **X**（**单次受击伤害上限** / **平砍封顶**；**X** 为条目参数）。                                                                                                                     |
| E-PASS-FIRST-DEATH-REVIVE    | 残命回潮 / 假死（暂定）       | **第一次死亡**时**复活**；可配置：**复活后血量比例**、**是否清除状态**、**是否仅触发一次**、**复活后是否弱化**等——**待定**。                                                                                              |
| E-PASS-BACKLOG-DEATH-BURST | 积压殉爆 / 亡溢（暂定）      | 战斗中按条目约定**积累「积压」层数**（占位名；**每触发一次 +1 层**）。**触发来源**在 `EnemyRoster` **写死**（常见候选：**每次自身行动完毕** / **每回合一次** / **每次受击** / **每次击伤玩家**：**待定**）。**层数上限**、是否 **HUD 显示**：**待定**。该敌人**死亡时**（血量归零；与 **§1.6**、**复活**、**分裂** 的先后：**待定**），对**玩家**造成**一次爆发伤害**（物理管道）：**B + k × 积压层数**（**B、k** 为条目参数，或改查表：**待定**）。与 **固定数值死亡爆炸**（§1.6 方向 A）同条时须写明是**替换**、**叠加**还是**取较高**：**待定**。 |
| E-PASS-FIRST-HITS-ZERO     | 前几击无效 / 虚无格挡（暂定）   | **前 X 次**受到的**伤害**在结算时视为 **0**（**X** 为条目参数；是否仅限**物理**、是否含 **DoT/伤口**：**待定**）。**X** 耗尽后本被动**失效**（或转为负面惩罚：**待定**）。 |
| E-PASS-OPEN-SLEEP-ACTIONS  | 开局沉眠 / 蛰伏（暂定）      | **战斗开始时**进入**沉睡**。**前 X 次**轮到本敌人、且按规则本应**执行行动栏一格**时，改为**不执行该格效果**，并消耗 **1** 次沉睡计数（**X** 为条目参数；**X** 用尽后**苏醒**，之后按正常 AI 出招）。沉睡期间是否仍**消耗/积累行动值**、行动栏**指针是否进位**、是否可与玩家侧**眩晕**复用图标与提示：**待定**。 |
| E-PASS-ON-HIT-HALVE-AP   | 受击顿挫 / 行动迟滞（暂定）   | **每次被攻击**时，将自身**当前行动值**变为原来的 **50%**（**减少一半**；与 §1 表中 **行动值**同义，条目/UI 若写作「**行动力**」应与此对齐）。**「被攻击」**口径（是否须实际扣血、护盾全吃是否触发）与 **DoT/伤口**、**多段伤害**是否逐段触发：**待定**。**×0.5 后下限**（如不低于 **0** / **1**）、**小数取整**规则：**待定**。 |
| E-PASS-WOUND-TARGET-HALVE-AP | 破势钉刺 / 顿挫转嫁（暂定） | **每次击伤**目标时，将**目标当前行动值**变为原来的 **50%**（**减少一半**；目标默认指**玩家**；**行动值**口径与 §1 一致，UI 写作「**行动力**」时应与此对齐）。**击伤**是否与 `E-PAS-WOUND-STR` 及本表「击伤」小结**同一判定**（仅扣血 / 护盾吸收是否算、多段是否逐次触发）：**待定**。**×0.5 后下限**、**取整**：**待定**（可与 `E-PASS-ON-HIT-HALVE-AP` 对齐）。 |
| E-PASS-ACTION-GATE-WHILE-ALLIES-LIVE | 伴存锁招 / 缚誓（暂定） | **在全部同伴死亡（或离场）之前**，本敌人行动栏中**指定的若干槽位**轮到执行时**不执行该格效果**（视为**空过**）。**同伴全灭**后锁定**解除**，被锁格恢复正常。哪些槽被锁、**同伴**判定与 §1.4 一致，在 `EnemyRoster` **写死**。场上**无同伴**（单敌遭遇）时：**待定**（通常等价于**无锁定**，或条目禁止进单敌池）。**空过时**是否仍视为「执行了一次行动」以消耗行动值、指针是否进位：**待定**。 |

### 1.4 敌人特色机制——保护同伴

> **语义**：该敌人以「保全另一名敌方单位」为核心行为动机，通过规则迫使玩家调整集火顺序或资源分配。

| 项目 | 说明 |
| ----- | ----- |
| **适用前提** | 场上存在 **至少 2 个敌方单位**（护援者 + 被保护者）。单场单敌遭遇时，本特色**不可配置**（条目不允许进入单敌池）。 |
| **常见实现方向（可多选叠加）** | **伤害转移**：同伴受到的部分/全部伤害改由护援者承担（或先扣护援者护盾）。**护罩/分摊**：护援者行动给同伴加护盾、减伤或「护援」状态。**治疗**：护援者通过行动（如 §1.3 `E-ACT-ALLY-HEAL`）**回复同伴 X 生命**。**目标偏好**：护援者存活时，强制或软引导玩家攻击顺序（如破护援前同伴获得高额减伤）。**行动封锁**：**同伴未全灭前**，护援者（或本体）**部分行动栏格不执行**（空过），全灭后解锁高威胁招式；见 §1.4.2 与被动 `E-PASS-ACTION-GATE-WHILE-ALLIES-LIVE`。 |
| **条目配置** | 在 `EnemyRoster` 中写明：护援对象判定规则（固定 ID 配对 / 场上唯一「脆弱体」标签）、数值参数（转移比例、护盾量、冷却或行动栏节奏）。 |
| **与池子** | 建议放在 **中后段池（B/C/D）** 或 **Boss 多阶段召唤**，避免与阶段 1 教学池抢复杂度。 |


#### 1.4.1 变体：同伴受伤时由自己代承（双倍）

> **语义**：**同伴**即将结算伤害时，改由 **本条目** 承受；且代承量按 **双倍** 计算，迫使玩家优先处理护援者或拆链。

| 项目 | 说明 |
|------|------|
| **触发** | 指定 **同伴** 受到**一次伤害事件**时（在扣血/扣盾前或按统一伤害管道：**待定**），伤害**改结算到本条目**上（同伴本次 **0** 或仅保留部分穿透：**待定**）。 |
| **双倍** | 转移到本条目上的伤害量 = 同伴**若无代承时本应受到**的该次伤害 × **2**（倍率可在条目中改为 **1.5× / 3×** 等，但默认文案取 **2×**）。 |
| **与 §1.4「伤害转移」** | 属于 **高代价转移**：护援者血量消耗更快，集火优先级通常上升。 |
| **条目配置** | `EnemyRoster` 中写明：**同伴判定**（同 §1.4）、**倍率**（默认 2）、是否对 **DoT/伤口** 分别生效、是否与 **自爆**（§1.6）同条及顺序。 |

**待细化**

- **多段伤害**：每一段是否单独触发代承与双倍，或整次攻击合并为一次代承。
- **范围攻击（AOE）**：同时命中护援者与同伴时，是否 **重复代承**、或仅对「以同伴为主目标」的一路生效。
- **护盾 / 易伤 / 伤口**：倍率前基础伤害在 **谁身上** 读取（以同伴面板为准还是以护援者为准）。
- **「本应受到」**：是否包含被同伴 **护甲/被动** 减免前的原始伤害，还是取 **最终扣血值** 再 ×2。


#### 1.4.2 变体：同伴未全灭前部分行动不执行

> **语义**：只要场上仍有**条目定义的同伴**存活，本敌人**若干行动栏格**保持「封印」；**同伴全部死亡（或离场）**后，节奏陡升。被动模板 **`E-PASS-ACTION-GATE-WHILE-ALLIES-LIVE`** 提供统一 ID，细则在条目中写死。

| 项目 | 说明 |
|------|------|
| **锁定条件** | 与「**同伴全部死亡之前**」同义：**尚有同伴存活**（场上 **≥1** 名条目定义的同伴）时锁定生效；**同伴数 = 0**（全灭或离场）后解除。 |
| **锁定表现** | 轮到**被锁槽位**时：**不执行**该格伤害/治疗/增益等（**空过**）。是否仍消耗本次**行动值**、**指针是否进位**：与被动表「待定」对齐，条目中择一写死。 |
| **槽位配置** | `EnemyRoster` 写明：**锁槽 2～3**、或**仅解锁槽 1**、或按**行动模板 ID** 黑名单等，避免与 AI「循环顺序」歧义。 |
| **设计用途** | 先清同伴再面对**完全体**Boss 式节奏；或护援者在同伴存活期只打**低威胁循环**，同伴全灭后露出**大招格**。 |


### 1.5 敌人特色机制——分裂

> **语义**：单位在特定条件下「一分为二 / 为多」，场上敌方数量或威胁形态发生变化。若仅需 **单体变强**、不增殖，见 **§1.7 限时进化**。

| **敌方槽与行动** | 子体各自占用**独立敌方行动值轮次**，与母体及彼此共享回合积累；子体行动栏按自身条目配置执行。 |

| **入场时机** | 分裂后子体立即入场并开始积累行动值；死亡动画与分裂结算的先后顺序在 `EnemyRoster` 写明。 |
| **与奖励/胜利** | 须清空所有子体才算胜利；子体被击杀是否视为独立击杀、是否影响奖励：在 `EnemyRoster` 写明。 |

### 1.6 敌人特色机制（草案）——自爆流

> **语义**：以 **主动或被动的一次性爆发** 换伤害或场面变化，逼迫玩家控制 **集火时机、护盾与血量**。可与 **§1.5 分裂**、**复活**、**护伴** 等叠加，但条目内需写清 **结算顺序**（先爆再裂 / 先裂再爆等）。

| 项目 | 说明 |
|------|------|
| **典型方向 A：死亡爆炸** | **被击杀时**（或血量归零瞬间）对玩家造成 **一次物理伤害**（系数、是否吃护甲/护盾顺序：**待定**）；可与 **§1.5.1 死亡二分裂** 同条配置：「先结算爆炸伤害 → 再生成两子体」或相反，**必须在条目写死**。 |
| **典型方向 D：积压殉爆** | 被动 **`E-PASS-BACKLOG-DEATH-BURST`**（§1.3.1）：存活期按规则**叠「积压」层**，**死亡时**对玩家**爆发伤害**且**随层数放大**（公式 **B + k×层数** 等）。与方向 A 同条时须写明**只保留一种爆炸**或**两段结算**及顺序；与 **复活 / 分裂** 的链式关系同方向 A。 |
| **典型方向 B：自爆行动** | 行动栏中含 **自爆** 类行动：消耗行动值发动，**对自身造成致命伤害或强制离场**，并对玩家造成 **AoE/单体大伤害**；适合快回合压迫。 |
| **典型方向 C：计时引爆** | 开战或某行动后获得 **倒计时**（回合数或 tick）；到时若仍存活则 **自爆**（伤害量可高于方向 A）；可被净化/打断与否：**待定**。 |
| **与分裂** | **死亡爆炸 + 死亡二分裂**：可做成「爆完再裂成两个较弱单位」或「仅爆炸不裂」——二选一，避免未写明时双重递归。 |
| **与池子** | 建议 **B/C/D** 或 **Boss 阶段**；阶段 1 若出现，应用 **低系数** 或 **长倒计时** 做教学。 |
| **条目配置** | `EnemyRoster` 中写明：爆炸 **基础倍率 / 平直伤害**、是否 **无视护盾部分**、**是否可闪避**、与 **子体条目 ID（若裂）** 的链式关系。 |

### 1.7 敌人特色机制（草案）——限时进化（变强）

> **语义**：自开战或自某标记起，在 **短时间窗口内若未被击杀**，单位 **不进分裂**、不增加敌方槽位，而是在 **原单位上进化**：数值与/或机制 **变强**，形成 **软狂暴**（与 §1.5.2「限时分裂」同属「拖越久越糟」，但 **场上单位数不变**）。
>
> **与 §1.5.2 的区别**：§1.5.2 超时 → **增殖**（多体）；§1.7 超时 → **强化**（单体仍是一个 ID，或同一槽位内阶段切换）。

| 项目 | 说明 |
|------|------|
| **触发** | 与 §1.5.2 类似：**T** 窗口内未被击杀则触发（**T** 口径：回合 / tick / 敌人行动次数：**待定**）。 |
| **进化表现（可多选）** | **属性倍率**：攻/血/护/速上调。**行动栏替换或追加**：解锁更强招式、缩短消耗。**新被动挂载**：如每回合 + 力量、受伤上限提高。**部分回血**：进化瞬间回复 **X%** 最大生命。**外观阶段**：立绘/特效阶位变化（美术）。 |
| **阶段与上限** | 默认 **一阶进化**（0→1）；条目可配置 **多阶**（1→2→…）与 **全场最多进化次数**，防无限叠层。 |
| **计时** | 进化后计时是否 **重置**、是否仅触发 **一次**、进化后窗口是否更短（二阶压力）：**待定**。 |
| **单场 1 敌** | **友好**：不依赖多敌方槽即可表达「越拖越强」。 |
| **与分裂 / 自爆同条** | 若同一条目同时具备 **限时进化** 与 **分裂/自爆**，须写清 **优先级**（如：先进化再判断是否超时分裂；或进化后取消分裂计时等），避免规则打架。 |
| **与池子** | 建议 **B/C/D** 或 **Boss**；阶段 1 若使用，应用 **长窗口** 或 **弱进化幅度** 做教学。 |
| **条目配置** | `EnemyRoster` 中写明：**T**、每阶 **数值倍率表**、**行动栏阶段表**（或引用备用条目 ID 做形态切换）、**UI 倒计时** 是否显示。 |

**待细化**

- 进化时是否 **清除** 自身 debuff / 保留伤口等。
- 进化是否 **打断** 当前行动值队列或重置行动指针。
- 玩家 **控制/眩晕** 冻结计时的规则是否与 §1.5.2 一致。

## 2. 层段敌人池与随机遭遇

> **规则（已确认）**：每个层段内配置**多个**具体敌人；每次进入该层段的**普通遭遇**，从池中**随机抽取**一个敌人条目出战。  
> Boss 层（5 / 10 / 15 / 20）使用 **Boss 池** 或固定条目，抽取规则可单独约定（如必为 Boss、或 Boss + 权重）。


| 层段             | 普通遭遇池 | 说明                               |
| -------------- | ----- | -------------------------------- |
| 阶段 1：普通层 1～4   | 池 A   | 多个独立敌人条目；每次遭遇**随机抽取**其一          |
| 阶段 2：普通层 6～9   | 池 B   | 同上；可与池 A 复用 ID 时用层段倍率/机制差分，或全新条目 |
| 阶段 3：普通层 11～14 | 池 C   | 待定                               |
| 阶段 4：普通层 16～19 | 池 D   | 待定                               |


- Boss 层（5 / 10 / 15 / 20）不使用 A～D 普通池，而用各阶段 **Boss 池**（或固定 Boss 条目）。
- **单场可容纳 2～4 个敌方单位**，护伴（§1.4）、分裂（§1.5）、协同行动（§1.3 `E-ACT-ALLY-*`）等机制按原设计落地。
- 遭遇时随机抽取的敌方单位数由遭遇表决定（基础为 1 个，中后期层可出多敌）。
- 敌人共享玩家同一套行动值积累与执行规则，按行动值高低排序轮动。
- 各池内敌人清单、随机权重、遭遇时敌方数量分布：**待填表**（见 §6）。

### 2.1 阶段 1（普通层 1～4，池 A）——「白板 / 较弱」数量建议

> 目标：前几层随机遭遇里，经常出现**好懂、好打**的敌人，避免开局全是机制怪；同时池里仍要有带轻机制的条目做铺垫。


| 类型           | 建议数量（在池 A 总数内）  | 说明                                                                             |
| ------------ | --------------- | ------------------------------------------------------------------------------ |
| **弱特色 / 白板** | **2～3 名**       | 行动栏以 1～2 招**纯输出或极简单交替**为主；**无复杂被动**，或仅有可忽略的装饰级效果；**数值**取池内偏低档（血量/攻击/护甲任一侧略低即可） |
| **带轻机制**     | 1～2 名           | 用于教学：如小额护盾、低层数伤口、单次易伤等，规则一眼能读完                                                 |
| **池 A 总规模**  | 约 **4～6 名**（可调） | 上两行相加；具体名单进 `EnemyRoster`                                                      |


- 「没有特色」不等于共用同一条数据：仍可按 **独立条目** 做不同立绘/图标与微小数值差，只是**机制深度刻意做浅**。
- 若希望第 1～2 层**必出**更弱的子集：可再拆 **池 A-浅**（仅 1～2 层权重）与 **池 A-深**（3～4 层），属实现细节，此处不锁死。

## 3. 原型（Archetype，可选标签）

> 用于归类、文案与策划沟通；**实际出战的是带完整配置的敌人条目**，不必与下表 1:1。新敌人可只填条目表、不强行贴标签。


| 原型 ID    | 暂定名 | 定位       | 行为摘要                                        | 典型行动栏（2～3 格）            |
| -------- | --- | -------- | ------------------------------------------- | ----------------------- |
| BRUTE    | 重锤型 | 肉盾、慢节奏   | 蓄力后高伤；可配 **未破蓄**（`E-PASS-FORCE-CHARGE-UNTIL-FIRST-HIT` + `E-ACT-CHARGE-TICK`）：**挨打前**只叠势，破蓄后接爆发                               | **阵前蓄力** + 高倍率普攻 / 重击        |
| SKIRM    | 掠袭型 | 快攻、干扰    | 低伤高频；挂伤口或闪避窗口；可配 **受击顿挫**（`E-PASS-ON-HIT-HALVE-AP`）使**连打推迟**其出招；或 **攻带盾**（`E-ACT-STRIKE-GAIN-SHIELD`） | 低消耗攻击 + 自保（护盾/减伤状态）     |
| SENTINEL | 禁卫型 | 护盾守门     | 叠盾、破盾前难击杀；**攻带盾**（`E-ACT-STRIKE-GAIN-SHIELD`）；**危盾赌局**（`E-ACT-BULWARK-GAMBIT`）：**盾未破**则**下一攻击×2**，**盾破**则**自晕**；或 **铁壁架式**（`E-ACT-STANCE-HALF-DAMAGE-TAKEN`） | 举盾/护盾获得 + 中伤攻击；或 **钢垒对赌** + 普攻（逼迫破盾或硬吃翻倍）；或 **刃盾连击** 与中伤交替；或 **半伤守势** + 反击/高威胁格 |
| BERSERK  | 狂战型 | 血线压制     | 自损换输出；低血更猛；可配 **击伤吸血**（`E-ACT-STRIKE-HEAL-ON-WOUND`）                                  | 扣血增伤类 + 普攻；或 **噬命斩** 与中伤交替              |
| THORN    | 棘缚型 | 反制输出     | 受击反馈；惩罚无脑连打；或 **聚势架式**（`E-ACT-STANCE-STRENGTH-ON-HIT`）：**下一出招前**被攻则叠**力量** | 普攻 + 反伤/荆棘类被动；或 **架式** + 高消耗爆发格 |
| CONTROL  | 牵制型 | 控制节奏     | 易伤、虚弱、跳过行动等；**迟缓**（`E-ACT-APPLY-SLOW-STACK`）：**速度 -1**/层；**回合放血**（`E-PASS-TURN-DRAIN-TARGET-HP`）；**击伤削条**（`E-PASS-WOUND-TARGET-HALVE-AP`） | 易伤/虚弱/缚足 + 中伤攻击          |
| GUARDIAN | 护伴型 | 保护同伴     | 伤害转移、给同伴护盾/减伤、**同伴治疗**（`E-ACT-ALLY-HEAL`）、**伴存锁招**（`E-PASS-ACTION-GATE-WHILE-ALLIES-LIVE`，§1.4.2）；**变体 §1.4.1**：同伴受伤由自己代承且 **双倍** | 护援/治疗类行动 + 普攻或低威胁干扰技；或同伴存活期仅低压循环、全灭后解锁高威胁格       |
| SPLITTER | 分裂型 | 增殖 / 软狂暴 | **死亡二分裂**（默认 N=2）或 **限时分裂**（§1.5）；改变场上单位数或威胁 | 常配合普攻或低频率干扰；核心在被动或触发而非栏位花样 |
| BOMBER | 自爆型 | 爆发交换 | **死亡爆炸**、**积压殉爆**（`E-PASS-BACKLOG-DEATH-BURST`，拖越久/动越多越痛）、**自爆行动**或 **倒计时引爆**（§1.6）；与分裂、复活同条时需写结算顺序 | 常含 1 招铺垫（易伤/加速自爆/叠积压）+ 普攻或短冷却干扰 |
| EVOLVER | 进化型 | 限时变强 | **短时间内未击杀则进化**（§1.7）：属性/行动栏/被动升级；**不增加**敌方单位数 | 前期偏弱招式 + 进化后高压招式；或纯被动驱动数值跳变 |
| NULLGUARD | 空挡型 | 前几击免伤 | **前 X 次受伤为 0**（被动 `E-PASS-FIRST-HITS-ZERO`）；耗尽后威胁上升 | 免伤期内低威胁骚扰 + 耗尽后高威胁输出 |
| DORMANT | 蛰伏型 | 开局少动 | **开局沉睡 X 个行动**（`E-PASS-OPEN-SLEEP-ACTIONS`）；给玩家**免费输出窗口**，苏醒后节奏变快或伤害变高 | 苏醒后以快攻或高消耗大招为主；或苏醒触发一次性强化 |


**与旧版「腐化」系列的关系**：可视为同一世界观下的简化标签；精简版可先只用上表 **ID + 暂定名**，正式文案再统一。
