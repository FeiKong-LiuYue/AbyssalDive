## 核心目标

---

## 核心六大机制

| 机制 | 说明 |
|------|------|
| 击伤 | 核心伤害触发，造成实际生命值扣除 |
| 连击 | 多次攻击相关，累积层数触发追加攻击 |
| 蓄力 | 临时物理伤害加成，一次性消耗 |
| 护盾 | 独立于生命值的防护系统 |
| 溃伤 | 持续伤害（溃伤统一） |
| 基础类 | 简单浅机制内容 |
