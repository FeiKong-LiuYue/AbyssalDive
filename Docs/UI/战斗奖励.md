# 潜渊（Abyssal Dive）- 战斗奖励界面

> 状态：重新设计中
> 基准：横屏（16:9）

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 战斗奖励界面 |
| 类型 | 单场战斗结束后跳转页面 |
| 触发 | 每场战斗胜利后 |
| 退出 | 点击继续下潜进入下一场战备 |

**设计目标：** 画面简洁、决策直观、延续横屏布局风格

---

## 三、顶部标题区

| 内容 | 设计 |

| 副标题 | 小字标注"第X层通关" |

---

## 四、中部奖励卡片区

### 4.1 布局规则

| 规则 | 说明 |
|------|------|
| 卡片数量 | 固定3张 |
| 排布方式 | 横向均匀排布 |
| 翻页 | 不设置滑动翻页 |

### 4.2 单张卡片内容

| 区域 | 内容 |
|------|------|
| 顶部 | 奖励类型图标 |
| 中部 | 奖励名称 |
| 下方 | 效果说明 |
| 底部 | 属性变化预览 |

### 4.3 视觉区分

| 品级 | 边框色调 |
|------|----------|
| 普通奖励 | 幽蓝色边框 |
| 优质奖励 | 暗金色边框 |

### 4.4 交互

| 交互 | 效果 |
|------|------|
| 点击 | 卡片高亮锁定，代表选定 |
| 未选择 | 继续下潜按钮灰度锁定 |

---

## 五、底部功能区

| 按钮 | 状态 |
|------|------|
| 继续下潜 | 已选择奖励后正常点亮，未选择灰度锁定 |
