# 潜渊（Abyssfall）- 战斗奖励界面

> 状态：最终定稿（可直接落地）
> 位置：UI/战斗奖励.md

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 战斗奖励界面 |
| 类型 | 单场战斗结束后跳转页面 |
| 触发 | 每场战斗胜利后 |
| 退出 | 点击继续下潜进入下一场战备 |

**设计目标：** 画面简洁、决策直观、低开发成本，延续深渊暗黑视觉风格

---

## 二、全局视觉标准

| 规范 | 说明 |
|------|------|
| 底色 | 焦黑底色（#121014）+ 深渊暗纹、做旧蚀刻纹理 |
| 普通奖励 | 幽蓝色调 |
| 优质奖励 | 暗金色调 |
| 面板样式 | 半透明深色底板+细荧光边框+边缘破损细节 |
| 交互 | 仅点击选中+悬浮信息预览，按下：荧光亮起+符文闪烁，无多余跳转层级 |
| 动效 | 静态画面，仅悬浮提亮（省性能、省美术） |
| 整体风格 | 偏厚重、做旧、蚀刻、裂纹、简洁决策直观 |

---

## 三、整体布局结构

```
┌─────────────────────────────┐
│                             │
│      [结算标题区域]          │  ← 居中标题+战斗小结
│                             │
├─────────────────────────────┤
│                             │
│   ┌─────┐ ┌─────┐ ┌─────┐   │
│   │奖励1│ │奖励2│ │奖励3│   │  ← 固定2-3张卡片
│   └─────┘ └─────┘ └─────┘   │    横向均匀排布
│                             │    无滑动翻页
│         [继续下潜]          │  ← 底部确认按钮
│                             │
└─────────────────────────────┘
```

---

## 四、顶部标题区

| 内容 | 设计 |
|------|------|
| 标题 | 居中放置战斗胜利提示文字，字体高亮醒目 |
| 副标题 | 小字简要标注本局战斗小结（氛围点缀，不展示繁杂数据） |
| 装饰 | 无多余插画与特效，保持画面清爽 |

---

## 五、中部奖励卡片区

### 5.1 布局规则

| 规则 | 说明 |
|------|------|
| 卡片数量 | 固定2-3张 |
| 排布方式 | 横向均匀排布 |
| 翻页 | 不设置滑动翻页 |
| 尺寸 | 统一尺寸，间距规整 |

### 5.2 单张卡片内容

| 区域 | 内容 |
|------|------|
| 顶部 | 奖励类型图标 |
| 中部 | 奖励名称 |
| 下方 | 精简效果说明（直白标注强化作用） |
| 底部 | 属性变化预览（选取前后数值/能力差距） |

### 5.3 视觉区分

| 品级 | 边框色调 |
|------|----------|
| 普通奖励 | 幽蓝色边框点缀 |
| 优质奖励 | 暗金色边框凸显质感 |

**说明：** 用色调深浅区分，不做花哨特效

### 5.4 交互效果

| 交互 | 效果 |
|------|------|
| 鼠标悬浮 | 卡片轻微提亮，展开完整效果注解 |
| 点击卡片 | 卡片高亮锁定，代表选定该增益 |

---

## 六、底部功能区

**继续下潜按钮**

| 状态 | 效果 |
|------|------|
| 已选择奖励 | 按钮正常点亮，可点击 |
| 未选择 | 按钮灰度锁定，不可点击 |
| 点击后 | 直接跳转至下一场战备界面，无二次确认弹窗 |

---

## 七、奖励类型适配展示

### 行动类卡片

| 类型 | 标注 | 示例 |
|------|------|------|
| 行动升级 | 行动强化后的效果、等级变化 | 连打 Lv.1→Lv.2 / 伤害 10→15 |
| 行动解锁 | 解锁新行动名称和类型 | 解锁「重击」/ 解锁「蓄力」 |

### 特性类卡片

| 类型 | 标注 | 示例 |
|------|------|------|
| 特性升级 | 特性强化后的效果、等级变化 | 铁壁 Lv.1→Lv.2 / 减伤 5%→10% |
| 特性解锁 | 解锁新特性名称和效果 | 解锁「战意」/ 解锁「连击」 |

### 强化类卡片

| 类型 | 标注 | 示例 |
|------|------|------|
| 属性增幅 | 血量、护盾、基础属性提升数值 | 攻击力 +1（10→11）/ 血量上限 +5（100→105）/ 速度 +0.1（1.0→1.1） |
| 栏位扩容 | 行动栏格子解锁 | 解锁第4格 / 解锁第5格 |

---

## 八、开发取舍优化点

| 优化项 | 说明 |
|--------|------|
| 静态画面 | 全程采用静态画面，仅保留悬浮提亮的简易反馈 |
| 素材复用 | 卡片样式统一复用模板，仅替换文字与图标 |
| 舍弃冗余 | 舍弃奖励剧情弹窗、多分支选择、道具预览等 |
| 精简信息 | 用短句替代长文本，降低读取压力 |
| 固定布局 | 整体布局固定不变，无需做复杂自适应调试 |

## 九、游玩流程

```
战斗结束 → 进入奖励页面 → 浏览全部奖励
→ 查看增益详情 → 点击选定奖励 → 点击按钮进入下一轮备战
```
