## 四、分区布局原则

### 战斗界面分区
- 顶部：信息栏 + ATB进度条
- 中间：敌我双方左右对立（横屏空间优势）
- 底部：状态栏 + 行动栏

### 战备界面分区
- 左侧：敌人信息（35%宽度）
- 右侧：玩家配置（65%宽度）
- 动线：看敌人 → 看自己 → 改配置 → 出发

## 五、组件设计

### 按钮样式
- 形状：圆角矩形 + 边缘小破损
- 背景：暗黑石底
- 边框：细金线 + 裂纹
- 按下：荧光亮起 + 符文闪烁
- 满级技能（质变）：边框发光 + 闪电小图标

### 血条/护盾条
- 血条：暗红底 + 黑色裂纹
- 护盾：幽蓝半透明 + 能量流动
- 掉血/破盾：碎片飞溅动画
- 血量降低时色调同步加深，强化视觉警示

### ATB进度条
```
[敌1 ▓▓▓▓░░░] [敌2 ▓▓░░░░░] ··· [玩家 ░░░░░░]
```
- 竖向填充表示行动值积累
- 行动值满的单位高亮
- 从左到右按行动值高低排列

### 状态图标
- 小型化收纳
- 点击/悬浮弹出效果说明
- 示例：显示为小图标列表

### 行动池配色
| 类型 | 色调 |
|------|------|
| 连击类 | 暗红系 |
| 击伤类 | 暗青蓝 |
| 蓄力类 | 暗金 |
| 护盾类 | 暗蓝灰 |
| 溃伤类 | 暗紫 |
| 基础类 | 灰色 |

### 奖励品级
| 品级 | 色调 |
|------|------|
| 普通奖励 | 幽蓝底色 |
| 优质奖励 | 暗金底色 |

### 文字风格
- 标题：古符文风格 + 描金
- 内容：纤细无衬线体 + 微光
- 数字：机械/遗迹数字

### 弹窗风格
- 背景：石板碎裂 + 深渊黑雾
- 边框：古老金属包边
- 标题：符文亮起

## 七、Unity适配

### 分辨率规范
- 目标分辨率：1920×1080（16:9横屏）
- 适配方案：安全区适配 + 动态锚点
- 资源尺寸：所有UI切图导出2倍分辨率

### UI层级设计
1. 底层：背景纹理、场景底图
2. 中下层：战斗角色/敌人展示区
3. 中层：血条、护盾条、状态图标
4. 中上层：技能按钮、功能按钮
5. 上层：弹窗、提示文字、特效遮罩
