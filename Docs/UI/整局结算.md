# 潜渊（Abyssal Dive）- 整局结算界面

> 状态：重新定稿中
> 定位：横屏（16:9）游戏标准

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 整局结算界面 |
| 类型 | 整局探险终结页面 |
| 触发 | 通关成功或角色陨落时 |
| 退出 | 点击再次下潜/返回主菜单 |

**设计原则：** 偏厚重、做旧、蚀刻、裂纹、结构极简、信息精简、风格区分结局氛围

---

## 二、全局视觉规范

| 规范 | 说明 |
|------|------|
| 背景 | 焦黑底色（#121014）+ 深渊暗纹，做旧蚀刻纹理，无动态特效 |
| 面板 | 半透明磨砂底板+边缘破损细节+细荧光边线 |
| 动效 | 仅文字、按钮悬浮高亮，按下：荧光亮起+符文闪烁 |
| 排版 | 内容居中收拢，视觉动线自上而下 |

## 四、上方结局主题区

### 胜利场景

| 元素 | 设计 |
|------|------|
| 标题 | 深渊征服 |
| 色调 | 暗金色调渲染画面 |
| 边框 | 暗金色面板边框 |
| 亮度 | 整体适度提升 |

### 失败场景

| 元素 | 设计 |
|------|------|
| 标题 | 陨落 |
| 色调 | 暗沉幽蓝冷色调 |
| 画面 | 整体偏灰暗 |
| 边框 | 暗幽蓝面板边框 |
| 亮度 | 整体降暗 |

---

## 五、中部数据统计区

### 展示数据（精选核心）

| 数据项 | 说明 |
|--------|------|
| 抵达深渊层数 | 最终到达层数 |
| 累计战斗场次 | 本局战斗总次数 |
| 累计获得强化次数 | 行动升级/属性增幅总次数 |
| 最高连击数值 | 最高连击数 |
| 剩余生命护盾终值 | 最终状态 |

### 设计要求
- 规整列表排布
- 文字紧凑排列
- 一目了然

## 六、下方功能按钮区

| 按钮 | 优先级 | 样式 |
|------|--------|------|
| 再次下潜 | 主按钮 | 尺寸更大，色调高亮 |
| 返回主页 | 次要按钮 | 样式简约低调 |

---

## 七、结局差异化

| 场景 | 边框 | 亮度 | 基调 |
|------|------|------|------|
| 通关成功 | 暗金色 | 适度提升 | 冲破黑暗的质感 |
| 探险失败 | 暗幽蓝 | 整体降暗 | 压抑，贴合陨落设定 |

## 八、游玩流程

```
对局结束 → 跳转结算页 → 查看本局游玩数据
→ 浏览结局画面 → 选择重启探险或返回主菜单
```
