# UI设计统一规范

> 日期：2026-05-24
> 状态：已统一

---

## 一、屏幕方向

**横屏（16:9）** — 所有界面统一

原因：
- 支持 X vs Y 多单位战斗
- ATB进度条横向展开更直观
- 敌我双方左右对立，符合传统RPG直觉
- 空间充裕，信息不拥挤

## 四、配色规范

### 主色调
| 用途 | 色值 |
|------|------|
| 背景底 | #121014 |
| 面板底色 | #1D1A21 |
| 边框/描边 | #2E2A34 |

### 强调色
| 用途 | 色值 |
|------|------|
| 玩家主色 | #C42048（暗红荧光） |
| 能量/行动点 | #2090C4（幽蓝荧光） |
| 危险/敌人 | #7020C4（暗紫荧光） |
| 金色符文 | #B89A6A（哑光金） |

| 状态 | 色值 |

## 六、ATB进度条

- 竖向填充表示行动值积累
- 从左到右按行动值高低排列
- 无具体数字，纯视觉展示
- 行动值满的单位高亮
