# 潜渊（Abyssfall）- 主菜单界面

> 状态：最终定稿（可直接落地）
> 位置：UI/主菜单.md

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 主菜单界面 |
| 类型 | 游戏启动初始页面 |
| 功能 | 所有流程入口 |
| 退出 | 点击按钮进入对应页面 |

**设计原则：** 偏厚重、做旧、蚀刻、裂纹、风格贴合深渊题材、功能精简无冗余

---

## 二、全局视觉规范

| 规范 | 说明 |
|------|------|
| 背景 | 焦黑底色（#121014）+ 深渊暗纹底图（幽暗深渊纹路），无动态光影特效 |
| 字体 | 高亮无衬线字体，标题加粗醒目，功能文字简洁利落 |
| 交互 | 按下：荧光亮起+符文闪烁（无复杂动画、无粒子特效） |
| 整体 | 偏厚重、蚀刻纹理、暗纹底、不堆砌华丽元素、视觉沉稳 |

---

## 五、中部功能按钮区

### 按钮排序（按游玩使用频率）

| 优先级 | 按钮 | 功能 | 状态 |
|--------|------|------|------|
| 1 | 继续下潜 | 读取本地存档，接续上一次探险进度 | 有存档正常点亮，无存档灰度锁定 |
| 2 | 开始下潜 | 开启全新一局冒险，重置所有本局进度 | 始终可点击 |
| 3 | 深渊手记 | 游戏介绍板块（世界观/机制/玩法） | 页面内精简文本，无多层子页面 |
| 4 | 系统设置 | 基础调节功能 | 亮度/音效/音乐开关 |

### 系统设置内容（精简）

| 设置项 | 说明 |
|--------|------|
| 整体亮度 | 调节屏幕亮度 |
| 音效音量 | 游戏音效音量 |
| 背景音乐开关 | 开启/关闭背景音乐 |

**排除项：** 无画面画质/按键自定义等复杂功能

### 按钮样式
- 圆角矩形+边缘小破损、细金线+裂纹
- 等间距竖向排列
- 按下：荧光亮起+符文闪烁

## 七、交互流程

| 流程 | 说明 |
|------|------|
| 启动游戏 | 直接进入主菜单 |
| 点击按钮 | 一键跳转目标页面，无二次确认弹窗 |
| 退出子页面 | 可直接返回主菜单，层级简单不嵌套 |

---

## 八、单人开发适配优化

| 优化项 | 说明 |
|------|------|
| 固定布局 | 整套页面为固定静态布局，无需适配复杂多端自适应逻辑 |
| 组件复用 | 所有按钮、面板样式复用已有界面组件，减少素材制作数量 |
| AI素材 | 仅依靠配色与文字区分功能，依靠AI即可快速生成背景与标识素材 |
| 代码逻辑 | 存档校验、页面跳转功能易编写调试 |
| 性能 | 全程轻量化视觉效果，运行无性能负担 |
