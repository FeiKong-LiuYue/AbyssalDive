# 潜渊（Abyssal Dive）- 战备界面

> 状态：重新设计中
> 基准：横屏（16:9）

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 战备界面 |
| 类型 | 战斗前置唯一界面 |
| 触发 | 每一场深渊战斗开始前强制进入 |
| 退出 | 点击开始下潜进入战斗 |

**设计目标：** 零冗余、高信息效率、横屏布局适配 X vs Y 多单位战斗

---

## 三、左侧区域｜敌人预览模块

### 3.1 展示内容

| 内容 | 说明 |
|------|------|
| 敌人头像 | 紧凑排列，显示本次战斗所有敌人 |
| 敌人名称 | 每位敌人名称标注 |
| 极简威胁标签 | 核心机制提示短句 |

### 3.2 威胁标签示例

| 标签 | 含义 |
|------|------|
| 高爆发 | 敌人伤害极高 |
| 持盾减伤 | 护盾阶段难以击杀 |
| 持续腐蚀 | 持续造成负面状态 |
| 高速连动 | 行动速度快 |
| 召唤型 | 会召唤小怪 |

### 3.3 悬浮交互

| 交互 | 效果 |
|------|------|
| 悬浮头像 | 弹出小型提示框，展示敌人核心机制一句话说明 |
| 无点击弹窗 | 无多余分页 |

---

## 四、右侧区域｜玩家完整备战区域

### 4.1 玩家状态面板

**显示内容（本局恒定核心属性）：**

| 数据 | 说明 |
|------|------|
| 当前血量 | 玩家当前/最大血量 |
| 当前护盾 | 护盾值 |
| 基础属性 | 攻击力、护甲、速度（精简数值） |
| 全局状态 | 小图标排列显示 |

### 4.2 行动栏｜出战配置区

**规则：**

| 规则 | 数值 |
|------|------|
| 初始格数 | 3格 |
| 最大上限 | 5格 |

**UI表现：**

| 状态 | 显示 |
|------|------|
| 已占用格子 | 高亮显示行动图标+名称+等级 |
| 空格子 | 边缘破损的暗色边框留白 |
| 上限标记 | 暗金细线标记容量上限 |

**重置排布按钮：**

| 项目 | 说明 |
|------|------|
| 位置 | 行动栏右侧小按钮 |
| 功能 | 一键清空当前行动栏 |
| 目的 | 符合快节奏肉鸽，方便快速重配组合 |

### 4.3 行动池｜可选行动库

**布局规则：**

| 规则 | 说明 |
|------|------|
| 分组方式 | 自动按类型分组排布 |
| 组标题 | 小字分类（暗蓝灰次级字） |
| 行动卡片 | 显示图标、名称、等级、简短效果预览 |

**行动池配色：**

| 类型 | 色调 |
|------|------|
| 连击类 | 暗红系 |
| 击伤类 | 暗青蓝 |
| 蓄力类 | 暗金 |
| 护盾类 | 暗蓝灰 |
| 溃伤类 | 暗紫 |
| 基础类 | 灰色 |

**交互逻辑：**

| 交互 | 效果 |
|------|------|
| 点击行动池行动 | 放入行动栏空位 |
| 点击行动栏已有行动 | 撤回行动池 |
| 逻辑 | 双向可逆、无需拖拽 |

---

## 五、底部固定按钮

**开始下潜**

| 项目 | 说明 |
|------|------|
| 样式 | 圆角矩形+边缘小破损+细金线+裂纹 |
| 位置 | 界面最底部居中 |
| 触发条件 | 所有配置完成即可点击 |

---

## 六、完整界面流程闭环

```
进入战备 → 浏览左侧敌人威胁 → 查看右侧自身状态
→ 调整行动栏组合 / 重置排布 → 确认配置 → 进入战斗
```
