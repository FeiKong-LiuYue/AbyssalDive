# 潜渊（Abyssfall）- 战备界面

> 状态：最终定稿（可直接落地）
> 位置：UI/战备界面.md

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 战备界面 |
| 类型 | 战斗前置唯一界面 |
| 触发 | 每一场深渊战斗开始前强制进入 |
| 退出 | 点击开始下潜进入战斗 |

**设计目标：** 零冗余、高信息效率、不卡流程、单人开发极易落地

---

## 二、全局视觉规范（全界面统一）

| 规范 | 说明 |
|------|------|
| 底色 | 焦黑底色（#121014）+ 深渊暗纹 |
| 主光色 | 幽蓝（常规信息）、暗金（关键/可交互信息） |
| 面板样式 | 边缘破损、石材质感、细边框、半透明深色底 |
| 字体 | 偏厚重无衬线、信息层级分明、重点高亮、次要压暗 |
| 动效 | 按下：荧光亮起+符文闪烁（省性能、省美术） |

---

## 三、整体布局结构

```
┌─────────────────────────────┐
│                             │
│      上半区：敌情预览        │  ← 固定占比 35%
│      （敌人信息区）          │
│                             │
├─────────────────────────────┤
│                             │
│      下半区：玩家备战区      │  ← 固定占比 65%
│      （状态/行动栏/行动池）  │
│                             │
├─────────────────────────────┤
│        [开始下潜]            │  ← 底部固定常驻按钮
└─────────────────────────────┘
```

**阅读动线：** 看敌人 → 看自己 → 改配置 → 出发

---

## 四、上半区｜敌人预览模块

### 展示内容

| 内容 | 说明 |
|------|------|
| 敌人头像图标 | 紧凑横向排列，显示本次战斗所有敌人 |
| 敌人名称 | 每位敌人名称标注 |
| 极简威胁标签 | 核心机制提示短句，不展示完整技能 |

### 威胁标签示例

| 标签 | 含义 |
|------|------|
| 高爆发 | 敌人伤害极高 |
| 持盾减伤 | 护盾阶段难以击杀 |
| 持续腐蚀 | 持续造成负面状态 |
| 高速连动 | 行动速度快 |
| 召唤型 | 会召唤小怪 |

### 交互设计

| 交互 | 效果 |
|------|------|
| 悬浮 | 弹出小型提示框，展示敌人核心机制一句话说明 |
| 无点击弹窗 | 无多余分页 |
| 无复杂词条 | 仅提供预判关键行为的信息 |

---

## 五、下半区｜玩家完整备战区域

### 布局结构

```
┌─────────────────────────────┐
│  玩家状态面板  │  行动栏    │  ← 上半部分
│  （血量/护盾/属性/Buff）    │  （已配置行动）
├─────────────────────────────┤
│                             │
│         行动池              │  ← 下半部分
│       （可选行动库）         │
│                             │
└─────────────────────────────┘
```

---

### 5.1 玩家状态面板

**显示内容（本局恒定核心属性）：**

| 数据 | 说明 |
|------|------|
| 当前血量 | 玩家当前/最大血量 |
| 当前护盾 | 护盾值 |
| 基础常驻属性 | 攻击力、护甲、速度（精简数值） |
| 全局状态Buff | 小图标排列显示（包含所有状态类型：正向增益/资源/防御/DOT等） |

**设计原则：**
- 面板紧凑、信息高密度
- 无效、过渡、次级数据全部隐藏
- 不占多余空间

---

### 5.2 行动栏｜出战配置区

**规则：**

| 规则 | 数值 |
|------|------|
| 初始格数 | 3格 |
| 最大上限 | 5格 |

**UI表现：**

| 状态 | 显示 |
|------|------|
| 已占用格子 | 高亮显示行动图标+名称+等级 |
| 空格子 | 边缘破损的暗色边框留白，直观显示可放置空位 |
| 上限5格位置 | 暗金细线标记容量上限 |

**新增功能：重置排布按钮**

| 项目 | 说明 |
|------|------|
| 位置 | 行动栏右侧小按钮 |
| 样式 | 圆角矩形+边缘小破损 |
| 功能 | 一键清空当前行动栏 |
| 交互 | 无确认弹窗，一键直接重置 |
| 目的 | 符合快节奏肉鸽，方便快速重配组合 |

---

### 5.3 行动池｜可选行动库

**布局规则：**

| 规则 | 说明 |
|------|------|
| 分组方式 | 自动按类型分组排布 |
| 组标题 | 小字分类（暗蓝灰次级字） |
| 行动卡片 | 显示图标、名称、等级、简短效果预览 |

**视觉区分（纯配色区分，无需美术资源）：**

| 类型 | 色调 |
|------|------|
| 攻击类 | 暗青蓝（沉稳） |
| 防御/护盾类 | 暗蓝灰（深沉） |
| 蓄力/爆发类 | 暗金（保留） |
| 持续状态类 | 暗紫（深沉） |

**交互逻辑：**

| 交互 | 效果 |
|------|------|
| 点击行动池行动 | 放入行动栏空位 |
| 点击行动栏已有行动 | 撤回行动池 |
| 逻辑 | 双向可逆、简单干净 |
| 实现方式 | 无需拖拽（降低开发量） |

---

## 六、底部固定按钮

**开始下潜**

| 项目 | 说明 |
|------|------|
| 样式 | 圆角矩形+边缘小破损+细金线+裂纹 |
| 位置 | 界面最底部居中 |
| 尺寸 | 最大、最高优先级 |
| 触发条件 | 所有配置完成即可点击 |
| 弹窗 | 无前置多余检查弹窗 |

---

## 七、完整界面流程闭环

```
进入战备 → 浏览敌人威胁 → 查看自身状态
→ 调整行动栏组合 / 重置排布 → 确认配置 → 进入战斗
```

**特点：** 零卡顿、零多余弹窗、零无效步骤

---

## 八、适配单人开发的轻量化设计优势

| 优势 | 说明 |
|------|------|
| 布局固定 | 无需自适应复杂逻辑 |
| 分组靠配色+文字 | 不需要大量美术资源 |
| 交互逻辑极简 | 双向点击进出，代码量极低 |
| 信息必要且最小化 | 无冗余系统拖累迭代 |
| 适配整套机制 | 蓄力、连击、行动链、ATB战斗完全适配 |

---

## 九、界面最终特点总结

- 流程直观、博弈前置
- 行动组合自由可调、支持快速重配
- 信息干净、不遮挡、不混乱
- 风格统一贴合深渊暗黑废墟
- 极致适配单人独立开发落地
