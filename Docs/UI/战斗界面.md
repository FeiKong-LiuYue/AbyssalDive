# 潜渊（Abyssfall）- 战斗界面

> 状态：最终定稿（可直接落地）
> 位置：UI/战斗界面.md

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 战斗界面 |
| 类型 | 核心ATB战斗页面 |
| 触发 | 战备完成后进入 |
| 退出 | 战斗胜利/失败/撤退 |

**设计目标：** 简洁轻量化，无传统行动条显示，视觉重心聚焦战场与行动栏

---

## 二、整体风格

| 维度 | 说明 |
|------|------|
| 风格 | 暗调废墟暗黑风、偏厚重、做旧、蚀刻、裂纹 |
| 画面 | 偏暗沉低饱和 |
| 纹理 | 锈蚀、水渍、裂纹复古质感、边缘破损 |
| 界面 | 简洁轻量化，功能聚焦战场与行动栏，无冗余 |
| 色彩 | 深灰、暗青、暗红为主色调 + 暗红/幽蓝/暗紫荧光 |
| 边框 | 磨损斑驳纹路、金属锈蚀细节 |

## 四、顶部区域

| 元素 | 设计 |
|------|------|
| 战斗名称 | 居中展示本场战斗名称、场景标识 |
| 字体效果 | 侵蚀做旧效果 |
| 左侧 | 敌方核心状态图标 |
| 右侧 | 玩家核心状态图标 |

### 状态图标（双方通用）
- 仅展示：血量、专属护盾、异常印记图标
- 无数值进度长条
- 图标直观显示持续周期

### ATB行动进度条
- 可视化进度条（纯视觉，无数字显示）
- 展示敌我双方行动顺位
- 进度条填充表示行动值积累
- 直观体现行动先后顺序
- 无具体数值标注，保持画面简洁

## 五、上方敌方面板

### 敌方站位区

| 元素 | 设计 |
|------|------|
| 敌方立绘 | 画面上半区域展示敌方立绘/模型 |
| 名称标注 | 敌人脚下标注名称 |
| 特性标签 | 敌人脚下标注特性标签（核心机制提示，如：高爆发、持盾减伤） |
| 状态图标 | 身旁悬浮小型状态图标组，显示所有状态类型（正向增益/资源/防御/DOT负向等） |
| 微型行动栏 | 每个敌人有独立微型行动指示器（仅显示当前行动状态） |

### 节奏暗示
- 隐藏敌方内置节奏计时提示
- 仅用微光特效暗示敌方行动循环
- 不做数字进度展示
- 敌人行动顺序通过微型行动栏视觉暗示

---

## 六、中部战场区域

### 对战交互核心

| 元素 | 设计 |
|------|------|
| 角色对峙 | 界面中心展示战斗画面 |
| 攻击触发 | 画面特效、光影闪烁、打击动画反馈 |
| 蓄力触发 | 角色周身浮现专属特效光晕 |
| 连击触发 | 画面角落浮现连击数字计数 |

### 连击机制
- 攻击触发后画面角落浮现连击数字计数
- 无专属进度面板
- 计数随中断自动清零

### 蓄力机制
- 开启蓄力时角色周身浮现专属特效光晕
- 单次攻击命中后特效消散
- 增益同步失效
- 无蓄力数值条

## 八、底部行动栏区域

### 行动栏摆放区

| 元素 | 设计 |
|------|------|
| 布局 | 界面最底端横向排列 |
| 操作 | 配置/执行行动为主要操作方式 |
| 执行 | 按行动栏顺序循环执行 |

### 行动约束
- 冷却时间
- 资源储备（如蓄力层数）
- 效果触发条件
- 受行动值积累进度约束

## 十、界面细节补充

### 全程摒弃传统行动体系UI组件
- 不存在行动条
- 不存在行动点数
- 不存在行动剩余次数显示模块

### 战斗节奏体现方式
| 方式 | 说明 |
|------|------|
| ATB行动进度条 | 可视化进度（纯视觉，无数字），直观展示行动顺序 |
| 状态印记 | 展示各类状态持续 |
| 行动冷却 | 行动冷却时间 |
| 特效反馈 | 视觉特效反应 |
| 连击计数 | 角落数字计数 |

### 数值信息弱化展示
- 优先用视觉特效、图标替代数字面板
- 保证画面沉浸感

### 状态图标说明
- 显示所有状态类型（正向增益/资源/防御/DOT负向）
- 每种状态有独立图标
- 图标显示当前层数
- 状态衰减时视觉反馈（层数减少动画）
- 护盾每回合减半视觉暗示（护盾条渐变）
