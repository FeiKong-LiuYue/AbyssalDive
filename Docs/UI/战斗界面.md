# 潜渊（Abyssal Dive）- 战斗界面

> 状态：重新设计中
> 基准：横屏（16:9），X vs Y 多单位战斗

---

## 一、界面定位

| 维度 | 内容 |
|------|------|
| 名称 | 战斗界面 |
| 类型 | 核心ATB战斗页面 |
| 触发 | 战备完成后进入 |
| 退出 | 战斗胜利/失败/撤退 |

**设计目标：** 清晰展示多单位战斗，ATB进度直观，沉浸式战斗体验

---

## 二、设计原则

### 2.1 横屏布局（16:9）

横屏优势：
- 敌我双方左右对立，符合传统RPG直觉
- ATB进度条横向展开，多单位显示不拥挤
- 两侧可容纳多敌人/多友军

### 2.2 信息层级

| 层级 | 内容 | 优先级 |
|------|------|--------|
| 顶层 | ATB进度条 | 必须，始终可见 |
| 中层 | 战斗动画/伤害数字 | 必须，视觉焦点 |
| 下层 | 单位立绘+血条+状态 | 必须，敌我识别 |
| 底层 | 玩家状态+行动栏 | 必须，功能操作 |

## 四、顶部区域

### 4.1 信息栏

| 元素 | 位置 | 内容 |
|------|------|------|
| 战斗名称 | 左上 | 场景/敌人名称 |
| 回合数 | 中上 | 当前回合 |
| 菜单/撤退 | 右上 | 功能按钮 |

### 4.2 ATB进度条

**横排显示所有单位行动顺序**

```
[敌1 ▓▓▓▓░░░] [敌2 ▓▓░░░░░] [敌3 ▓░░░░░░]  ···  [玩家 ░░░░░░] [召唤 ░░░░░░]
```

设计要点：
- 竖向填充表示行动值积累
- 行动值满的单位高亮
- 从左到右按行动值高低排列（最左=即将行动）
- 无具体数字，纯视觉展示

## 五、中部战场区域

### 5.1 左右对立布局

```
左侧（敌方）                中央                  右侧（友方）
┌─────────────┐            ┌───┐            ┌─────────────┐
│  敌1 [立绘]  │            │VS │            │  玩家 [立绘] │
│     血条     │            └───┘            │     血条     │
│     状态     │                              │     状态     │
├─────────────┤                              ├─────────────┤
│  敌2 [立绘]  │                              │  召唤 [立绘] │
│     ...     │                              │     ...     │
└─────────────┘                              └─────────────┘
```

### 5.2 单位卡片设计

每个单位（敌人/友方）显示：

| 元素 | 说明 |
|------|------|
| 立绘 | 角色形象（可缩小显示） |
| 血条 | 下方横条，红色 |
| 护盾 | 血条上方横条，蓝色（如果有护盾） |
| 状态图标 | 小图标排列（最多显示4-5个） |
| 名称 | 单位名称（简化） |

### 5.3 行动动画区

- 中央区域显示当前行动
- 攻击动画、伤害数字飘出
- 特效光影反馈

### 5.4 连击/蓄力显示

- 攻击时画面角落浮现连击数字
- 蓄力时角色周围显示光晕

## 六、底部状态与行动栏

### 6.1 状态显示区

```
[连击3] [蓄力2] [易伤1]      ❤️ 80/100    🛡 15    [铁壁2]
```

- 左：核心资源（连击/蓄力/关键状态）
- 中：生命值和护盾（数字+图标）
- 右：其他状态图标

### 6.2 行动栏

```
┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│  连打  │  │  爆发  │  │  蓄力  │  │   -   │  │   -   │
│  Lv.2  │  │  Lv.1  │  │  Lv.1  │  │        │  │        │
└────────┘  └────────┘  └────────┘  └────────┘  └────────┘
```

- 5格上限
- 已配置行动显示图标+名称+等级
- 空格子显示为可添加状态

## 七、多单位显示策略

### 敌人数量：1-3个

| 数量 | 显示方式 |
|------|----------|
| 1 | 大尺寸居中 |
| 2 | 上下排列或左右排列 |
| 3 | 横向排列，适当缩小 |

### 友方数量：1-2个（玩家+召唤/伙伴）

| 数量 | 显示方式 |
|------|----------|
| 1 | 大尺寸玩家居右 |
| 2 | 玩家+召唤上下排列或并排 |

---

## 八、关键设计决策

1. **ATB进度条**：横向排列，无数字，纯视觉
2. **敌我左右对立**：符合横屏空间优势
3. **单位信息精简**：只显示关键信息（血条/护盾/状态图标）
4. **行动栏底部固定**：始终可操作
5. **伤害数字飘出**：中央区域显示
