## 二、深渊概念

| 要素 | 描述 |
|------|------|
| 深渊定义 | 一种侵蚀性的黑暗能量，侵蚀古老文明遗迹 |
| 深渊产物 | 被深渊能量扭曲的遗迹守护者/原住民 |
| 深渊效果 | 使生物形态扭曲、获得诡异荧光、产生变异能力 |
