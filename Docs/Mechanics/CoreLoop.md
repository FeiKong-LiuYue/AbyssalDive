Abyssal Dive- 核心循环

> 状态：已定稿

---

## 一、核心循环

```
下潜 → 触发战斗 → 战备（配置行动）→ 自动战斗 → 胜利获得奖励 → 继续下潜 / 失败重置
```

---

## 二、层数与阶段

| 项目 | 设计 |
|------|------|
| 总层数 | 20层 |
| 分组 | 4阶段 × 5层 |
| Boss层 | 第5/10/15/20层 |
| 每层结构 | 一波战斗 + 战备 |

---

## 三、战备阶段

| 设计 | 说明 |
|------|------|
| 可配置项 | 玩家手动选择上阵行动 |
| 行动栏 | 初始3格，上限5格 |
| 上阵数量 | 至少填满当前已解锁的全部栏位才能开战 |
| 执行顺序 | 玩家自由排序，同一行动可重复使用 |
| 槽位扩容 | 通过战后三选一属性增幅获得，最高5格 |

---

## 四、自动战斗

| 设计 | 说明 |
|------|------|
| 玩家操作 | 无（战备配置完，战斗全自动执行） |
| 执行方式 | 按行动栏顺序执行 |
| 执行逻辑 | 轮到某行动时自动执行该行动效果 |
| 影响因素 | 角色特性、角色状态 |
| 循环 | 行动栏执行完后，从第一个开始循环 |
