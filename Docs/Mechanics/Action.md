## 一、连击类

| 行动 | 1级 | 2级 | 3级 |
|------|-----|-----|-----|
| 连打 | 2次攻击各50%攻击力 | 3次攻击各50%攻击力 | 4次攻击各50%攻击力⚡ |
| 连斩 | 30%伤害，执行一次+1次攻击 | 40% | 50%⚡ |
| 追击 | 8伤害，击伤追加1次50%攻击力攻击 | 12伤害，追加1次50%攻击力攻击 | 15伤害，追加1次50%攻击力攻击，击伤必定附加1层溃伤⚡ |
| 连击延续 | 发起2次攻击，每次击伤额外获得1层连击 | 发起2次攻击，每次击伤额外获得2层连击 | 发起3次攻击，每次击伤额外获得2层连击⚡ |
| 连击狂热 | 发起1次攻击；连击≥3时，追加1次30%攻击 | 追加1次40%攻击；≥5时无视护盾 | 追加1次50%攻击；≥5时无视护盾；≥7时回复生命⚡ |
| 连击终结 | 连击≥5层时，额外发起1次全体攻击 | 全体攻击+20% | 全体攻击+40%⚡ |
| 连击追击 | 获得3层「奇袭」状态；每次发起攻击时，每层+10%追加攻击概率（100%攻击力），触发成功后减少1层 | 获得4层 | 获得5层⚡ |
| 连击警戒 | 获得3层「警戒」状态；受到攻击时，每层+10%反击概率（100%攻击力），触发成功后减少1层 | 获得4层 | 获得5层⚡ |
| 连击狂暴 | 消耗所有连击层数，每层转化为+1狂怒 | 每层+2狂怒 | 每层+3狂怒⚡ |
| 狂怒猛击 | 2次4伤害，每次击伤+1狂怒 | 3次5伤害，每次击伤+1狂怒 | 4次6伤害，每次击伤+1狂怒⚡ |
| 倾泻 | 消耗当前所有连击层数，每消耗1层发起1次50%攻击力攻击 | 每消耗1层发起1次60%攻击力攻击 | 每消耗1层发起1次75%攻击力攻击⚡ |
| 乘胜追击 | 1次攻击10伤害，击伤则立即执行下一行动 | 12伤害，击伤则立即执行下一行动 | 15伤害，击伤则立即执行下一行动⚡ |

## 七、行动通用属性

| 属性 | 说明 |
|------|------|
| 等级 | 1～3级，第3级可质变 |
| 行动栏 | 初始3格，上限5格 |
| 执行 | 按行动栏顺序循环执行 |
| 行动消耗 | 待定 |
| 跳过行动 | 更改下一执行行动为下一个，不影响当前已积累的行动值 |
| 无法执行 | 若一个行动无法执行，将被跳过 |

### 伤害计算公式

```
物理伤害 = (百分比属性加成 + 固定伤害加成 + 状态附加伤害) × 伤害倍率
```

| 组成部分 | 示例 | 说明 |
|---------|------|------|
| 百分比属性加成 | +50%攻击力 | 基础伤害乘区 |
| 固定伤害加成 | +12伤害 | 直接增加固定数值 |
| 状态附加伤害 | 蓄力层数×2、溃伤层数等 | 依据层数状态增加伤害 |
| 伤害倍率 | ×1.5 | 最终伤害放大 |

**示例：**

`（50%攻击力 + 12 + 5蓄力×2 + 溃伤×3层）× 1.0 = 最终物理伤害`
