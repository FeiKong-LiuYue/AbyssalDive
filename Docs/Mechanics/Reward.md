# 潜渊（Abyssal Dive）- 奖励系统

> 状态：已定稿
> 位置：Mechanics/Reward.md
> 说明：精简版奖励系统

---

## 一、奖励触发

| 时机 | 奖励 |
|------|------|
| 普通战斗胜利 | 三选一 |
| Boss战斗胜利 | 三选一（稀有度权重提升） |

---

## 二、奖励类型

### 2.1 行动类

| 类型 | 说明 |
|------|------|
| 行动升级 | 提升行动等级（Lv.1→Lv.2 或 Lv.2→Lv.3） |
| 行动解锁 | 解锁新行动（从行动库中选择） |

### 2.2 特性类

| 类型 | 说明 |
|------|------|
| 特性升级 | 提升特性等级 |
| 特性解锁 | 解锁新特性 |

### 2.3 强化类

| 类型 | 说明 |
|------|------|
| 属性增幅 | 攻击力+1 / 血量上限+5 / 速度+0.1 |
| 栏位扩容 | 解锁第4格行动栏 / 解锁第5格行动栏 |

---

## 三、奖励方式

### 三选一模式

| 规则 | 说明 |
|------|------|
| 选项数量 | 每次3个选项，选择1个 |
| 来源混合 | 可来自不同类别（行动/特性/强化） |
| 抽取范围 | 从未解锁或未升级满的条目中抽取 |
| 过滤规则 | 升级已满的条目不会出现在奖励池 |

---

## 四、奖励池结构

| 规则 | 说明 |
|------|------|
| 全量池 | 所有可获取奖励放入同一池子 |
| 稀有度分层 | 按阶段设置权重，阶段越高高稀有度出现概率越大 |
| 行动来源 | 从Mechanics/Action.md中抽取未解锁或未满级行动 |
| 特性来源 | 从Mechanics/Trait.md中抽取未解锁或未满级特性 |

---

## 五、行动栏扩容

| 栏位 | 解锁方式 |
|------|----------|
| 第1-3格 | 初始解锁 |
| 第4格 | 通过奖励解锁 |
| 第5格 | 通过奖励解锁 |

**规则：**
- 解锁后新格为空槽，可放入任意已解锁行动
- 未填满全部已解锁栏位时不可进入战斗

---

## 六、属性增幅规则

| 属性 | 增幅值 | 说明 |
|------|--------|------|
| 攻击力 | +1 | 直接增加固定伤害 |
| 血量上限 | +5 | 增加最大生命值 |
| 速度 | +0.1 | 增加每回合行动值积累 |

**示例：**
- 攻击力 10→11
- 血量上限 100→105
- 速度 1.0→1.1
