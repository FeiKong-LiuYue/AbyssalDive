## 一、战斗回合流程

```
1. 回合开始
   - 战意/铁壁等状态先触发
   - 护盾减半（向下取整）
   - 所有单位按速度积累行动值
2. 行动值达标的单位按高低顺序执行行动
3. 回合结束
```

---

## 二、行动值/时序系统

### 2.1 核心概念

| 概念 | 定义 |
|------|------|
| 速度 | 固定属性，决定每回合自然积攒的行动值多少 |
| 行动值 | 战斗内实时数值，每回合按自身速度累加 |
| 行动门槛 | 每个行动有固定消耗门槛，攒够≥门槛即可执行 |

### 2.2 结算流程

```
1. 进入新回合，所有在场单位同时按自身速度，累加行动值
2. 遍历全场，筛选行动值≥自身门槛的单位
3. 多单位同时达标时：按当前行动值高低排序，数值越高越优先
4. 单位执行行动后：扣除本次行动门槛值，剩余值保留到下回合
5. 未达门槛的单位：行动值保留，等待下回合继续累加
```

### 2.3 干扰规则

| 干扰方式 | 效果 |
|----------|------|
| 降低速度 | 减少每回合行动值增量 |
| 直接削减 | 直接扣除当前已有行动值 |
| 提高门槛 | 临时提高敌人行动所需门槛 |

## 三、战斗机制

| 机制 | 说明 |
|------|------|
| 护盾机制 | 吸收物理伤害，仅回合开始时减半 |
| 伤害计算 | 攻击力影响伤害，护甲不直接参与 |
| 行动值不重置 | 每次只扣消耗门槛，余量继承 |

---

## 四、回合结算顺序

```
受伤时：
1. 铁壁层数 −1
2. 触发铁壁免伤效果
3. 结算护盾、减伤，生命扣除

回合结束时：
1. 结算溃伤伤害
2. 易伤、虚弱、溃伤每回合自动衰减 1 层
```

## 五、多敌机制

### 5.1 同场规则

| 设计 | 说明 |
|------|------|
| 敌人数量 | 单场多名敌人同时在场 |
| 行动展示 | 每个敌人有独立微型行动栏，只显示当前行动状态 |
| AI逻辑 | 每个敌人独立速度/行动值/门槛，各自排队 |

### 5.2 协同羁绊

| 羁绊 | 敌人组合 | 效果 |
|------|----------|------|
| 强防御组合 | 纹盾祭者 + 逆刃守陵人 | 攻防反制一体 |
| 干扰压制组合 | 蚀影咒骸 + 静滞古尸 | 双重限制玩家行动 |
| 成长爆发组合 | 噬层畸兽 + 沉渊棺卫 | 前期隐忍后期爆发 |
| 召唤铺场组合 | 残魂引路人 + 墟骨哨卫 | 小怪分摊+全员强化 |
