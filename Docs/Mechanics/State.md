# 潜渊（Abyssfall）- 状态定义

> 状态：已定稿
> 说明：核心概念已迁移至「机制总览.md」

---

## 状态列表

### 正向增益

| 状态 | 效果 |
|------|------|
| 连击 | 每次发起攻击+1层；回合结束时若本回合未发起过攻击则清空 |
| 蓄势 | 每回合开始，获得等同于自身层数的蓄力 |
| 战意 | 回合开始+1层，层数越高伤害加成越高 |
| 力量 | 每层增加1点当前攻击力，可为负数 |
| 狂怒 | 每层增加5%物理伤害 |
| 疫病 | 击伤时，额外施加1层溃伤给目标，触发成功后减少1层 |
| 奇袭 | 每次发起攻击时，每层+10%追加攻击概率（100%攻击力），触发成功后减少1层 |
| 警戒 | 受到攻击时，每层+10%反击概率（100%攻击力），触发成功后减少1层 |

### 资源状态

| 状态 | 效果 |
|------|------|
| 蓄力 | 每层增加附加物理伤害1点；触发后清空 |

### DOT负向

| 状态 | 效果 |
|------|------|
| 易伤 | 层数越高，受到伤害越高 |
| 虚弱 | 层数越高，自身造成伤害越低 |
| 溃伤 | 层数越高，回合开始时受到溃伤伤害越高（无视护盾） |

### 防御

| 状态 | 效果 |
|------|------|
| 铁壁 | 受击消耗1层，每层抵消一次物理伤害 |

### 战斗属性

| 状态 | 效果 |
|------|------|
| 护盾 | 受到攻击时抵扣伤害，每层1点 |
| 守御 | 减少物理伤害，每层5%，每回合-1层，受击-1层 |
| 招架 | 回合结束时提供护盾，层数×护甲属性；生效后衰减1层 |
| 坚壁 | 护盾不自然衰减，每回合-1层 |
| 碎盾 | 护盾减少时触发1次效果（一次减少无论多少层只触发1次） |
| 破盾 | 护盾归零时触发1次效果 |
| 荆棘 | 受到攻击时，向攻击方施加荆棘层数的物理伤害 |
| 刺甲 | 受到攻击时，向攻击方施加刺甲层数的溃伤 |
| 治愈 | 每回合恢复层数血量，回合结束时衰减一半 |
| 威慑 | 存在时，若被攻击，降低攻击方1点临时力量 |
| 碎甲 | 造成物理伤害时，扣除目标等量于层数的护盾 |
| 结界 | 为全场友方提供伤害减免，来源死亡后消失 |

### 负向

| 状态 | 效果 |
|------|------|
| 眩晕 | 跳过回合 |

## 状态消耗类型

| 类型 | 状态 | 规则 |
|------|------|------|
| 回合衰减型 | 易伤/虚弱/溃伤/守御/招架/坚壁/荆棘/碎盾/眩晕/治愈/威慑/连击 | 每回合-1层 |
| 受击消耗型 | 铁壁 | 被物理攻击时-1层 |
| 永久叠层型 | 蓄势/战意/力量/狂怒 | 无衰减，战斗结束清空 |
| 主动消耗型 | 蓄力/疫病/奇袭/警戒 | 触发后减少1层 |
