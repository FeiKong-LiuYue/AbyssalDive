# 潜渊（Abyssfall）- 机制总览

> 状态：已定稿
> 位置：Mechanics/机制总览.md

## 一、核心概念

### 1.1 触发条件

| 触发条件 | 定义 |
|----------|------|
| 回合开始 | 回合开始时触发 |
| 回合结束 | 回合结束时触发 |
| 攻击 | 发起一次物理伤害的行为，一个行动可能发起多次攻击 |
| 击伤 | 当物理攻击对目标造成了实际伤害时 |
| 被攻击 | 受到物理攻击时 |
| 追击 | 发起攻击时，有概率触发一次追加攻击（100%攻击力）；追击触发的攻击无法再触发追击 |
| 反击 | 受到攻击时，有概率触发一次反击（100%攻击力）；反击触发的攻击可以触发追击 |
| 死亡 | 生命值归零时 |
| 击杀 | 击杀目标时 |
| 碎盾 | 护盾减少时触发1次效果（一次减少无论多少层只触发1次） |
| 破盾 | 护盾归零时触发1次效果 |

### 1.2 伤害类型

| 伤害类型 | 说明 | 可被减免 |
|----------|------|----------|
| 物理伤害 | 由攻击行为产生的伤害 | 可被护盾抵扣、可被守御减少 |
| 溃伤伤害 | 持续性伤害，回合开始时结算 | 无视护盾，无法被常规手段减免 |

### 1.3 战斗属性

| 属性 | 定义 |
|------|------|
| 攻击力 | 影响物理伤害的基础数值 |
| 血量 | 生命值，归零时死亡 |
| 护甲 | 影响护盾获取和部分防御效果 |
| 速度 | 每回合积累的行动值增量 |
| 行动值 | 实时数值，累积到门槛即可执行行动 |

### 1.4 行动（通常为瞬时）

| 要素 | 说明 |
|------|------|
| 定义 | 玩家或敌人主动执行的技能（通常为瞬时） |
| 描述 | 包含效果、消耗、等级 |
| 关联 | 属于一个分类，可能触发特性；如需持续效果，通过施加状态实现 |

### 1.4 状态（通常持续一场战斗）

| 要素 | 说明 |
|------|------|
| 定义 | 附着在目标身上的持续性效果（通常持续一场战斗） |
| 描述 | 包含效果、层数、消耗类型 |
| 关联 | 可被行动/特性施加，被特定条件消耗 |

### 1.5 特性（通常持续一局）

| 要素 | 说明 |
|------|------|
| 定义 | 被动触发的机制（通常持续一局） |
| 描述 | 包含效果、触发条件 |
| 关联 | 由敌人或玩家持有，特定条件触发；如需持续效果，通过施加状态实现 |

### 1.6 行动、状态、特性关联

```
行动/特性 ──→ 施加 ──→ 状态
    │                    │
    │                    ▼
    └── 触发 ──→ 特性 ←── 持有（敌人/玩家）
                        │
                        ▼
                     效果（影响战斗）
```

**说明：**
- 行动和特性都可以施加状态
- 如需持续效果，通过施加状态实现

## 二、六大核心机制

| 机制 | 说明 |
|------|------|
| 击伤 | 核心伤害触发，造成实际生命值扣除 |
| 连击 | 多次攻击相关，累积层数触发追加攻击 |
| 蓄力 | 临时物理伤害加成，一次性消耗 |
| 护盾 | 独立于生命值的防护系统 |
| 溃伤 | 持续伤害（溃伤统一） |
| 基础类 | 简单浅机制内容（回血、buff施加、状态施加等） |

**说明：**
- 六大核心机制是游戏设计的基础框架
- **玩家设计**应严格遵循六大机制
- **敌人设计**可以在六大机制基础上创新，允许独特的机制设计

## 三、状态系统

### 3.1 正向增益

| 状态 | 效果 |
|------|------|
| 连击 | 每次发起攻击+1层；回合结束时若本回合未发起过攻击则清空 |
| 蓄势 | 每回合开始，获得等同于自身层数的蓄力 |
| 战意 | 回合开始+1层，层数越高伤害加成越高 |
| 力量 | 每层增加1点当前攻击力，可为负数 |
| 狂怒 | 每层增加5%物理伤害 |
| 疫病 | 击伤时，额外施加1层溃伤给目标，触发成功后减少1层 |
| 奇袭 | 每次发起攻击时，每层+10%追加攻击概率（100%攻击力），触发成功后减少1层 |
| 警戒 | 受到攻击时，每层+10%反击概率（100%攻击力），触发成功后减少1层 |

### 3.2 资源状态

| 状态 | 效果 |
|------|------|
| 蓄力 | 每层增加附加物理伤害1点；触发后清空 |

### 3.3 DOT负向

| 状态 | 效果 |
|------|------|
| 易伤 | 层数越高，受到伤害越高 |
| 虚弱 | 层数越高，自身造成伤害越低 |
| 溃伤 | 层数越高，回合开始时受到溃伤伤害越高（无视护盾） |

### 3.4 防御

| 状态 | 效果 |
|------|------|
| 铁壁 | 受击消耗1层，每层抵消一次物理伤害 |
| 护盾 | 受到攻击时抵扣伤害，每层1点 |
| 守御 | 减少物理伤害，每层5%，每回合-1层，受击-1层 |
| 招架 | 回合结束时提供护盾，层数×护甲属性；生效后衰减1层 |
| 坚壁 | 护盾不自然衰减，每回合-1层 |
| 碎盾 | 每减少1层护盾，全体敌人受到1点物理伤害；每回合-1层 |
| 荆棘 | 受到攻击时，向攻击方施加荆棘层数的物理伤害 |
| 刺甲 | 受到攻击时，向攻击方施加刺甲层数的溃伤 |
| 治愈 | 每回合恢复层数血量，回合结束时衰减一半 |
| 威慑 | 存在时，若被攻击，降低攻击方1点临时力量 |
| 结界 | 为全场友方提供伤害减免，来源死亡后消失 |

### 3.5 负向

| 状态 | 效果 |
|------|------|
| 眩晕 | 跳过回合 |

## 四、状态消耗类型

| 类型 | 状态 | 规则 |
|------|------|------|
| 回合衰减型 | 易伤/虚弱/溃伤/守御/招架/坚壁/荆棘/碎盾/眩晕/治愈/威慑/连击 | 每回合-1层 |
| 受击消耗型 | 铁壁 | 被物理攻击时-1层 |
| 永久叠层型 | 蓄势/战意/力量/狂怒 | 无衰减，战斗结束清空 |
| 主动消耗型 | 蓄力/疫病/奇袭/警戒 | 触发后减少1层 |

## 五、伤害计算

```
物理伤害 = (百分比属性加成 + 固定伤害加成 + 状态附加伤害) × 伤害倍率
```

| 组成部分 | 示例 | 说明 |
|---------|------|------|
| 百分比属性加成 | +50%攻击力 | 基础伤害乘区 |
| 固定伤害加成 | +12伤害 | 直接增加固定数值 |
| 额外伤害 | 蓄力层数×2、溃伤层数等 | 依据层数状态增加伤害 |
| 伤害倍率 | ×1.5 | 最终伤害放大 |

**示例：**

`（50%攻击力 + 12 + 5蓄力×2 + 溃伤×3层）× 1.0 = 最终物理伤害`

## 六、行动分类

| 分类 | 定义 |
|------|------|
| 连击类 | 多次攻击相关，基于连击层数触发效果 |
| 击伤类 | 基于击伤触发条件触发效果 |
| 蓄力类 | 与蓄力机制相关的行动 |
| 护盾类 | 与护盾机制相关的行动 |
| 溃伤类 | 与溃伤机制相关的行动 |
| 基础类 | 简单浅机制（回血、buff施加、状态施加等） |

## 七、等级设计原则

| 等级 | 说明 |
|------|------|
| 初始级 | 基础效果 |
| 中间级 | 数值提升 |
| 最高级⚡ | 质变效果（效果性质改变或大幅强化） |

**约束：**
- 等级数量不固定，可为2-4级
- **满级质变原则**：最高等级必须有质变效果
