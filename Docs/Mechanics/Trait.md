### 输出收割系

| 特性 | 1级 | 2级 | 3级⚡ |
|------|------|------|-------|
| 断命利刃 | 敌人血量<30%时，攻击+6伤害 | +9伤害 | +13伤害；触发时敌人无法反击⚡ |
| 久战愈勇 | 每回合获得1层蓄力，叠加无上限 | +2层 | +3层⚡ |
| 尾击 | 回合结束时，发起1次30%攻击力的攻击 | 50% | 80%⚡ |
| 连击炽火 | 发起攻击时，该攻击额外伤害+1（基于本回合已攻击次数） | +2 | +3 |
| 追击回响 | 追击触发成功后，下个行动+10%行动积累值 | +15% | +20%⚡ |
| 反击回响 | 反击成功后，下个行动+10%行动积累值 | +15% | +20%⚡ |
| 连击护盾 | 存在连击层数时，受到攻击获得护盾，数值=当前连击层数 | ×1.5 | ×2⚡ |
| 溃伤传染 | 造成溃伤伤害时，30%几率传染1层溃伤给随机另一目标 | 45% | 60%⚡ |
| 溃伤扩散 | 施加溃伤时，30%几率额外传染1层溃伤给随机另一目标 | 45% | 60%⚡ |
| 溃伤加深 | 施加溃伤时，额外施加1层溃伤给目标 | +2层 | +3层⚡ |
| 溃伤侵蚀 | 造成溃伤伤害时，额外施加1层溃伤给目标 | +2层 | +3层⚡ |
| 溃伤治愈 | 造成溃伤伤害时，获得等同于伤害值20%的生命回复 | 30% | 40%⚡ |
