## 二、ATB速度系统

### 2.1 基础机制

| 规则 | 说明 |
|------|------|
| 基础频率 | 每回合1次常规行动 |
| 速度作用 | 影响行动值积累速度 |
| 行动成本 | 部分行动行动值高（慢），部分行动值低（快） |
| 累积方式 | 速度高 → 积累快 → 能更快执行下一个行动 |

### 2.2 行动值系统

```
每回合开始 → 按速度积累行动值
            ↓
行动值 ≥ 行动门槛 → 执行行动
            ↓
扣除行动门槛值，剩余保留 → 继续积累到下回合
```

### 2.3 行动频率（参考）

| 行动类型 | 行动值门槛 | 速度影响 |
|----------|------------|----------|
| 快行动 | 低（如8） | 高速度可连续执行 |
| 慢行动 | 高（如20） | 高速度也能积累到门槛 |

| 速度类型 | 行动频率 | 说明 |
|----------|----------|------|
| 快速 | >1次/回合 | 积累快，可更频繁行动 |
| 平均 | 1次/回合 | 常规速度 |
| 慢速 | <1次/回合 | 积累慢，行动间隔长 |

## 三、伤害公式

### 3.1 基础公式

```
最终伤害 = max(0, 原始伤害 - 护盾吸收 - 护甲值)
```

### 3.2 伤害构成

| 组成部分 | 说明 |
|----------|------|
| 原始伤害 | 来自行动/特性/状态的伤害 |
| 护盾吸收 | 护盾抵扣伤害（护盾优先于护甲） |
| 护甲减免 | 护甲值直接扣除伤害 |

### 3.3 护甲规则

| 规则 | 说明 |
|------|------|
| 护甲值范围 | ≥ 0（不能为负数） |
| 护甲作用 | 所有最终伤害都扣除护甲值 |
| 护盾优先级 | 先扣护盾，再扣护甲 |

### 3.4 护盾规则

| 规则 | 说明 |
|------|------|
| 护盾吸收 | 吸收伤害，每层1点 |
| 衰减 | 回合开始时护盾减半（向下取整） |
| 泛用性 | 吸收所有类型伤害 |
